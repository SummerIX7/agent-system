# G 代码基础

## 概述

G 代码（G-code）是数控机床最常用的编程语言，用于控制机床的运动轨迹、速度、加工方式等。G 代码由字母 G 后跟数字组成，称为准备功能指令。掌握常用 G 代码指令是数控编程的基础。本文重点讲解 G00、G01、G02、G03、G90、G91 等核心指令。

## 核心知识点

### 快速定位指令 G00

G00 指令用于刀具快速移动到指定位置，不进行切削加工。

📚 来源：GB/T 8870-2019 第4章第2节

**格式**：
```gcode
G00 X_ Z_  ; 车床
G00 X_ Y_ Z_  ; 铣床/加工中心
```

**示例**：
```gcode
G00 X100 Z50  ; 快速移动到 X100 Z50 位置
```

**注意事项**：
- G00 运动速度由机床参数设定，不可用 F 指令控制
- 运动轨迹不一定是直线，可能是折线（各轴以最大速度独立运动）
- 使用时需注意避免刀具与工件、夹具碰撞
- 通常用于加工前的定位和加工后的退刀

### 直线插补指令 G01

G01 指令用于刀具以指定速度进行直线切削运动。

📚 来源：GB/T 8870-2019 第4章第3节

**格式**：
```gcode
G01 X_ Z_ F_  ; 车床
G01 X_ Y_ Z_ F_  ; 铣床/加工中心
```

**示例**：
```gcode
G01 X50 Z-20 F0.2  ; 直线切削到 X50 Z-20，进给速度 0.2mm/r
```

**参数说明**：
- `F`：进给速度
  - 车床：G99 模式下单位为 mm/r（每转进给），G98 模式下为 mm/min
  - 铣床：G94 模式下单位为 mm/min（每分钟进给），G95 模式下为 mm/r

**完整示例**（车床加工外圆）：
```gcode
G00 X30 Z2       ; 快速定位到加工起点
G01 Z-30 F0.15   ; 车削外圆，长度 30mm
G01 X35          ; 退刀
G00 Z2           ; 快速返回
```

### 圆弧插补指令 G02/G03

- G02：顺时针圆弧插补
- G03：逆时针圆弧插补

📚 来源：GB/T 8870-2019 第4章第4节

**格式（圆心方式 I/J/K）**：
```gcode
G02 X_ Z_ I_ K_ F_  ; 车床（XZ 平面）
G02 X_ Y_ I_ J_ F_  ; 铣床（XY 平面）
```

**格式（半径方式 R）**：
```gcode
G02 X_ Z_ R_ F_
```

**参数说明**：
- I、J、K：圆心相对于起点的增量值（I 对应 X 轴，J 对应 Y 轴，K 对应 Z 轴）
- R：圆弧半径（正值为小圆弧，负值为大圆弧）

**示例**：
```gcode
; 顺时针圆弧，半径 R30
G02 X100 Z-50 R30 F0.15

; 使用圆心方式
G02 X100 Z-50 I30 K0 F0.15
```

**方向判断方法**：
- 站在第三轴正方向观察加工平面
- 顺时针为 G02，逆时针为 G03
- 车床 XZ 平面：从 Y 轴正方向观察

### 单位设定指令

| 指令 | 功能 | 说明 |
|------|------|------|
| G20 | 英制单位 | 单位为 inch |
| G21 | 公制单位 | 单位为 mm（默认） |

### 进给速度单位设定

| 指令 | 功能 | 适用机床 |
|------|------|----------|
| G94 | 每分钟进给 | 铣床（mm/min） |
| G95 | 每转进给 | 铣床（mm/r） |
| G98 | 每分钟进给 | 车床（mm/min） |
| G99 | 每转进给 | 车床（mm/r） |

### 固定循环指令

📚 来源：GB/T 8870-2019 第4章第5节

车床常用固定循环：

```gcode
; G90：外圆车削循环
G90 X40 Z-30 F0.2  ; 从当前位置车削到 X40 Z-30

; G94：端面车削循环
G94 X40 Z-5 F0.2   ; 车削端面

; G71：外圆粗车循环（复合循环）
G71 U2 R1           ; 每次切深 2mm，退刀 1mm
G71 P10 Q20 U0.5 W0.1 F0.3
N10 G00 X20         ; 精加工轮廓起点
G01 Z-30 F0.15
X40 Z-50
N20 X50             ; 精加工轮廓终点
```

铣床常用固定循环：

```gcode
; G81：钻孔循环
G81 X50 Y30 Z-20 R2 F100  ; 在 X50 Y30 处钻孔，深度 20mm

; G83：深孔钻削循环（排屑型）
G83 X50 Y30 Z-30 R2 Q5 F80  ; 每次切深 5mm，排屑后继续

; G80：取消固定循环
G80
```

## 常见问题

1. **G02/G03 方向判断错误**
   - 错误表现：加工出的圆弧方向相反
   - 解决方法：站在第三轴正方向观察加工平面，顺时针 G02，逆时针 G03

2. **进给速度单位混淆**
   - 错误表现：车床用 mm/min，铣床用 mm/r
   - 解决方法：车床 G98 为 mm/min、G99 为 mm/r；铣床 G94 为 mm/min、G95 为 mm/r

3. **G00 碰撞问题**
   - 错误表现：快速定位时刀具撞到工件或夹具
   - 解决方法：编程时确保安全高度，先 Z 轴退刀再 X/Y 轴移动

## 总结

- G00：快速定位，不切削，速度由机床参数决定
- G01：直线切削，需指定进给速度 F
- G02/G03：圆弧切削，注意方向判断和 I/J/K/R 参数
- G90/G91：绝对/增量坐标编程
- 固定循环（G71/G81/G83 等）简化重复性加工编程
- 刀具补偿（G41/G42/G43）保证加工精度
