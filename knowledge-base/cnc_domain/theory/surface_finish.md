# 表面粗糙度

## 概述

表面粗糙度是指加工表面上具有的较小间距和微小峰谷所组成的微观几何形状特征。它是衡量零件加工质量的重要指标，直接影响零件的配合性能、耐磨性、抗疲劳强度和抗腐蚀能力。数控编程人员必须理解表面粗糙度的标注方法及其与加工方法的对应关系。

## 核心知识点

### 表面粗糙度的评定参数

📚 来源：GB/T 1031-2009 第4章

| 参数 | 符号 | 定义 | 说明 |
|------|------|------|------|
| 轮廓算术平均偏差 | Ra | 取样长度内轮廓偏距绝对值的算术平均值 | 最常用 |
| 轮廓最大高度 | Rz | 取样长度内轮廓峰顶到谷底的最大距离 | 常用于较粗糙表面 |
| 轮廓微观不平度十点高度 | Rz | 取样长度内 5 个最大峰高和 5 个最大谷深的平均值之和 | 旧标准常用 |

**Ra 值系列**（μm）：
```
0.012, 0.025, 0.05, 0.1, 0.2, 0.4, 0.8, 1.6, 3.2, 6.3, 12.5, 25, 50, 100
```

### 表面粗糙度标注方法

📚 来源：GB/T 131-2006

新国标标注符号：

```
√  —— 基本符号（可用任何方法获得的表面）

   —— 去除材料方法获得的表面（车、铣、磨等）

   —— 不去除材料方法获得的表面（铸、锻、轧等）
```

标注示例：
```
Ra 0.8  —— 表面粗糙度 Ra 值为 0.8μm
Ra 1.6  —— 表面粗糙度 Ra 值为 1.6μm
Ra 3.2  —— 表面粗糙度 Ra 值为 3.2μm
```

### 常见加工方法与表面粗糙度对应关系

| 加工方法 | 表面粗糙度 Ra (μm) | 说明 |
|----------|---------------------|------|
| 粗车 | 12.5-25 | 去除大量材料 |
| 半精车 | 3.2-6.3 | 为精加工做准备 |
| 精车 | 0.8-1.6 | 一般配合面 |
| 精密车削 | 0.2-0.4 | 高精度配合面 |
| 粗铣 | 6.3-25 | 平面、型腔粗加工 |
| 精铣 | 1.6-3.2 | 平面、型腔精加工 |
| 磨削 | 0.1-0.8 | 高精度表面加工 |
| 研磨 | 0.012-0.1 | 超精密表面加工 |
| 钻孔 | 6.3-25 | 孔的粗加工 |
| 铰孔 | 0.8-3.2 | 孔的精加工 |
| 镗孔 | 0.8-3.2 | 大孔精加工 |

### 表面粗糙度与切削参数的关系

影响表面粗糙度的主要切削参数：

**1. 进给量 f**
```
理论粗糙度 Rmax = f² / (8 × r)

r：刀尖圆弧半径（mm）
f：每转进给量（mm/r）
```

示例：
- 刀尖圆弧半径 r = 0.8mm，进给量 f = 0.2mm/r
- Rmax = 0.2² / (8 × 0.8) = 0.00625mm = 6.25μm
- 对应 Ra ≈ 1.6-3.2μm

**2. 切削速度 Vc**
- 切削速度过低容易产生积屑瘤，增大粗糙度
- 适当提高切削速度可改善表面质量
- 存在一个最佳切削速度范围

**3. 刀尖圆弧半径 r**
- 刀尖圆弧半径越大，理论粗糙度越小
- 但过大会增大切削力和振动
- 精加工常用 r = 0.4-1.2mm

**4. 切削深度 ap**
- 切削深度对粗糙度影响较小
- 但精加工时切削深度不宜过大，避免让刀

### 表面粗糙度的选择原则

| 应用场景 | Ra 值 (μm) | 说明 |
|----------|------------|------|
| 非配合表面 | 6.3-25 | 无特殊要求 |
| 一般配合面 | 1.6-3.2 | 常规配合 |
| 精密配合面 | 0.4-0.8 | 滑动轴承、密封面 |
| 高精度表面 | 0.1-0.2 | 量具、精密导轨 |
| 超精密表面 | 0.012-0.05 | 光学元件 |

### 表面粗糙度的测量方法

| 方法 | 精度 | 适用场景 |
|------|------|----------|
| 比较样块比较法 | 低 | 现场快速检测 |
| 触针法（粗糙度仪） | 高 | 实验室精密测量 |
| 光切法 | 中 | 平面、圆柱面 |
| 干涉法 | 很高 | 超精密表面 |

## 常见问题

1. **如何通过调整切削参数改善表面粗糙度**
   - 降低进给量（最有效）
   - 适当提高切削速度
   - 增大刀尖圆弧半径
   - 使用切削液
   - 减小切削深度

2. **表面粗糙度与尺寸公差的关系**
   - 表面粗糙度是微观几何形状误差
   - 尺寸公差是宏观尺寸允许的变动范围
   - 一般公差等级越高，要求的表面粗糙度越低

3. **积屑瘤对表面粗糙度的影响**
   - 积屑瘤会增大表面粗糙度
   - 产生原因：切削速度过低、切削温度过高
   - 解决方案：提高切削速度、使用切削液、增大前角

## 总结

- Ra 是最常用的表面粗糙度评定参数
- 表面粗糙度与进给量、切削速度、刀尖圆弧半径密切相关
- 不同加工方法能达到的表面粗糙度范围不同
- 精加工时应根据图纸要求合理选择切削参数
- 表面粗糙度的选择应满足零件功能要求
