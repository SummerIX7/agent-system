# M 代码基础

## 概述

M 代码（Miscellaneous Function）是数控机床的辅助功能指令，用于控制机床的辅助动作，如主轴启停、冷却液开关、换刀等。M 代码与 G 代码配合使用，共同完成零件的加工过程。掌握常用 M 代码是数控编程的必备技能。

## 核心知识点

### 主轴控制指令

📚 来源：GB/T 8870-2019 第5章第2节

| 指令 | 功能 | 说明 |
|------|------|------|
| M03 | 主轴正转 | 从尾座方向看，主轴顺时针旋转（车床从卡盘方向看为逆时针） |
| M04 | 主轴反转 | 从尾座方向看，主轴逆时针旋转 |
| M05 | 主轴停止 | 主轴停止旋转 |

```gcode
M03 S1000  ; 主轴正转，转速 1000 r/min
G01 X50 Z-30 F0.2  ; 切削加工
M05        ; 主轴停止
```

**注意事项**：
- 启动主轴前必须指定转速 S
- M03/M04 必须在切削运动之前执行
- 换刀前必须先执行 M05 停止主轴
- 攻丝时需要 M03 和 M04 配合（正转攻入，反转退出）

### 冷却液控制指令

| 指令 | 功能 | 说明 |
|------|------|------|
| M07 | 雾状冷却 | 适用于高速加工、微量润滑 |
| M08 | 液状冷却 | 常规冷却液喷射 |
| M09 | 关闭冷却液 | |

```gcode
M03 S800 M08  ; 主轴正转 + 开冷却液
G01 X40 Z-20 F0.2
M09           ; 关冷却液
M05           ; 主轴停止
```

### 换刀指令

📚 来源：GB/T 8870-2019 第5章第3节

| 指令 | 功能 | 说明 |
|------|------|------|
| M06 | 自动换刀 | 将刀库中指定刀具换到主轴上 |

```gcode
M06 T01  ; 换 1 号刀具到主轴
```

换刀的标准流程（以加工中心为例）：
```gcode
G91 G28 Z0  ; Z 轴回参考点（安全高度）
M05          ; 主轴停止
M06 T02      ; 换 2 号刀
M03 S1200    ; 主轴正转
G43 H02 Z50  ; 刀具长度补偿
M08          ; 开冷却液
```

**注意事项**：
- 换刀前必须先将 Z 轴退到安全高度
- 换刀前必须停止主轴
- 车床换刀通常使用 T 指令（如 T0101，前两位为刀位号，后两位为刀补号）

### 程序控制指令

| 指令 | 功能 | 说明 |
|------|------|------|
| M00 | 程序暂停 | 无条件暂停，按循环启动键继续 |
| M01 | 选择暂停 | 面板上"选择停止"开关打开时暂停 |
| M02 | 程序结束 | 程序结束，不返回起点 |
| M30 | 程序结束并返回 | 程序结束，光标返回程序开头 |

```gcode
M03 S1000
G01 X50 Z-30 F0.2
M00        ; 暂停，检查工件尺寸
G01 X60 Z-40 F0.2
M30        ; 程序结束，返回开头
```

**M00 与 M01 的区别**：
- M00：无条件暂停，程序必须手动按"启动"才能继续
- M01：条件暂停，只有面板上"选择停止"开关打开时才暂停

**M02 与 M30 的区别**：
- M02：程序结束，光标停留在程序末尾
- M30：程序结束，光标自动返回程序开头（更常用）

### 其他常用 M 代码

| 指令 | 功能 | 说明 |
|------|------|------|
| M03 | 主轴正转 | 最常用 |
| M04 | 主轴反转 | 攻丝退出时使用 |
| M05 | 主轴停止 | 换刀、测量前使用 |
| M06 | 自动换刀 | 加工中心使用 |
| M08 | 开冷却液 | 切削加工时使用 |
| M09 | 关冷却液 | |
| M10 | 夹紧 | 夹紧第四轴或工作台 |
| M11 | 松开 | 松开第四轴或工作台 |
| M98 | 调用子程序 | 调用指定程序号的子程序 |
| M99 | 子程序结束 | 子程序返回主程序 |

### 子程序调用

📚 来源：GB/T 8870-2019 第5章第5节

```gcode
; 主程序
O0001
M03 S1000
G00 X0 Z0
M98 P1000 L3  ; 调用 O1000 子程序，重复 3 次
M30

; 子程序
O1000
G01 X50 F0.2
G01 Z-20
G01 X55
G00 Z2
M99  ; 子程序结束，返回主程序
```

## 常见问题

1. **M03 和 M04 的使用场景**
   - M03（正转）：大多数切削加工使用
   - M04（反转）：攻丝退出、特殊加工要求时使用

2. **换刀时忘记退刀**
   - 错误表现：在加工位置直接换刀，导致碰撞
   - 解决方法：换刀前执行 G91 G28 Z0 将 Z 轴退到参考点

3. **M00 和 M01 混淆**
   - M00：一定会暂停，用于需要检查的关键工序
   - M01：可选暂停，用于调试时临时检查

## 总结

- M03/M04/M05：主轴正转/反转/停止
- M07/M08/M09：冷却液控制
- M06：自动换刀（加工中心）
- M00/M01：程序暂停
- M02/M30：程序结束
- M98/M99：子程序调用/返回
- M 代码通常与 G 代码在同一行使用，按模态生效
