# 切削原理

## 概述

切削原理是数控加工的理论基础，涵盖切削变形机理、切削力分析、切削热产生与传导、刀具磨损机理等内容。理解切削原理有助于合理选择切削参数、延长刀具寿命、提高加工质量。

## 核心知识点

### 切削三要素

切削三要素是影响加工质量、刀具寿命和生产效率的三个核心参数。

📚 来源：《金属切削原理》(陈日曜, 2021) 第2章第1节

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 切削速度 | Vc | m/min | 刀具切削刃相对于工件的线速度 |
| 进给量 | f | mm/r 或 mm/min | 工件每转或每分钟刀具沿进给方向的位移 |
| 切削深度 | ap | mm | 已加工表面与待加工表面之间的垂直距离 |

**切削速度计算公式**：
```
Vc = π × D × n / 1000

Vc：切削速度（m/min）
D：工件直径（mm）
n：主轴转速（r/min）
```

**主轴转速计算**：
```
n = 1000 × Vc / (π × D)

示例：加工直径 50mm 的工件，切削速度 120 m/min
n = 1000 × 120 / (3.14159 × 50) ≈ 764 r/min
```

**进给速度计算**：
```
Vf = f × n

Vf：进给速度（mm/min）
f：每转进给量（mm/r）
n：主轴转速（r/min）
```

### 切削力

📚 来源：《金属切削原理》(陈日曜, 2021) 第3章第1节

切削力是刀具在切削过程中作用在工件上的力，直接影响加工精度、刀具寿命和机床功率。

切削力的三个分力：
- **主切削力 Fz**：沿切削速度方向的力，是最大的分力，消耗功率最多
- **进给力 Fx**：沿进给方向的力
- **背向力 Fy**：垂直于已加工表面的力

影响切削力的因素：
1. **工件材料**：材料硬度越高，切削力越大
2. **切削深度**：切削深度增大，切削力近似线性增大
3. **进给量**：进给量增大，切削力增大，但增大幅度小于切削深度
4. **切削速度**：速度增大，切削力略有下降
5. **刀具几何角度**：前角增大，切削力减小

经验公式：
```
Fz = CFz × ap^xFz × f^yFz × Vc^nFz × KFz

CFz：与工件材料相关的系数
xFz、yFz、nFz：指数
KFz：修正系数
```

### 切削热

📚 来源：《金属切削原理》(陈日曜, 2021) 第4章第1节

切削热是切削过程中因材料变形和摩擦产生的热量，导致工件和刀具温度升高。

切削热的来源：
1. **剪切区变形热**（约 60-70%）：材料在剪切面发生塑性变形产生的热量
2. **前刀面摩擦热**（约 20-30%）：切屑沿前刀面滑动产生的摩擦热
3. **后刀面摩擦热**（约 5-10%）：刀具后刀面与已加工表面的摩擦热

切削热的传导：
- **传入切屑**（约 60-80%）：切屑带走大部分热量
- **传入刀具**（约 10-20%）：导致刀具温度升高
- **传入工件**（约 3-10%）：导致工件热变形
- **传入周围介质**（约 1%）

切削温度对加工的影响：
- 温度过高会导致刀具磨损加速
- 工件热变形影响加工精度
- 已加工表面产生残余应力

### 刀具磨损

📚 来源：《金属切削原理》(陈日曜, 2021) 第5章第1节

刀具磨损是切削过程中不可避免的现象，直接影响加工质量和成本。

磨损形式：
1. **后刀面磨损**（VB）：最常见的磨损形式，后刀面与工件摩擦形成磨损带
2. **前刀面磨损（月牙洼磨损）**：切屑在前刀面上滑动形成凹坑
3. **崩刃**：刀具切削刃突然断裂
4. **塑性变形**：高温高压下刀具材料发生永久变形

磨损过程：
```
初期磨损期 → 正常磨损期 → 急剧磨损期
  (快)         (均匀)         (急剧)
```

磨损判据：
- 后刀面磨损带宽度 VB ≥ 0.3mm（精加工）
- 后刀面磨损带宽度 VB ≥ 0.6mm（粗加工）
- 加工表面粗糙度明显恶化
- 切削力突然增大
- 出现振动和异响

### 刀具材料

📚 来源：《金属切削原理》(陈日曜, 2021) 第6章第1节

| 刀具材料 | 硬度 | 耐热温度 | 适用场景 |
|----------|------|----------|----------|
| 高速钢 | 62-70 HRC | 550-600°C | 低速加工、复杂形状刀具 |
| 硬质合金 | 89-93 HRA | 800-1000°C | 最常用，适合大多数加工 |
| 陶瓷 | 93-95 HRA | 1200°C | 高速精加工 |
| 立方氮化硼 | 4000-5000 HV | 1300°C | 淬硬钢、高温合金加工 |
| 金刚石 | 10000 HV | 700°C | 有色金属、非金属精加工 |

## 常见问题

1. **切削参数选择原则**
   - 粗加工：大切削深度、大进给量、较低切削速度（追求效率）
   - 精加工：小切削深度、小进给量、较高切削速度（追求质量）

2. **如何判断切削参数是否合理**
   - 切屑形态：良好的切屑应为 C 形或 6 字形
   - 表面质量：无振纹、无毛刺
   - 刀具磨损：在正常范围内
   - 切削声音：平稳无尖锐声

3. **切削液的作用**
   - 冷却：降低切削区温度
   - 润滑：减少刀具与工件的摩擦
   - 排屑：冲走切屑
   - 防锈：保护已加工表面

## 总结

- 切削三要素（切削速度、进给量、切削深度）是控制加工质量的核心参数
- 切削力影响加工精度和刀具寿命，需合理选择切削参数
- 切削热导致工件变形和刀具磨损，需通过切削液和参数优化控制
- 刀具磨损有初期、正常、急剧三个阶段，需在急剧磨损前换刀
- 刀具材料选择需根据工件材料和加工要求综合考虑
