# 公差与配合

## 概述

公差与配合是机械制造中保证零件互换性和装配质量的核心标准体系。数控加工的最终目标就是将零件加工到图纸要求的公差范围内。理解公差标注、配合制度和测量方法是数控编程和操作人员的必备技能。

## 核心知识点

### 基本术语

📚 来源：GB/T 1800.1-2020 第3章

| 术语 | 定义 |
|------|------|
| 基本尺寸 | 设计给定的理论尺寸（图纸标注尺寸） |
| 实际尺寸 | 测量得到的实际尺寸 |
| 极限尺寸 | 允许的最大尺寸和最小尺寸 |
| 上偏差 | 最大极限尺寸 - 基本尺寸 |
| 下偏差 | 最小极限尺寸 - 基本尺寸 |
| 尺寸公差 | 最大极限尺寸 - 最小极限尺寸 |
| 零线 | 表示基本尺寸的一条直线 |

标注示例：
```
φ50H7
  ↑  ↑
  |  └── 公差等级 7 级
  └─── 基本尺寸 50mm，H 为基本偏差代号
```

### 标准公差等级

📚 来源：GB/T 1800.1-2020 第4章

标准公差等级共 20 级：IT01、IT0、IT1、IT2 ... IT18

| 等级 | 应用场景 | 典型加工方法 |
|------|----------|--------------|
| IT01-IT1 | 量块、精密测量工具 | 超精密加工 |
| IT5-IT6 | 精密配合面 | 磨削、精密车削 |
| IT7-IT8 | 一般配合面 | 车削、铣削 |
| IT9-IT10 | 非配合面 | 粗车、粗铣 |
| IT11-IT13 | 毛坯尺寸 | 铸造、锻造 |
| IT14-IT18 | 非加工面 | 无需加工 |

公差值计算（近似公式）：
```
IT = a × i

a：公差等级系数
i：标准公差因子（与基本尺寸有关）
```

### 基本偏差

📚 来源：GB/T 1800.1-2020 第5章

基本偏差是确定公差带相对于零线位置的那个偏差，用拉丁字母表示。

**孔的基本偏差**（大写字母）：A、B、C、CD、D、E、EF、F、FG、G、H、JS、J、K、M、N、P、R、S、T、U、V、X、Y、Z、ZA、ZB、ZC

**轴的基本偏差**（小写字母）：a、b、c、cd、d、e、ef、f、fg、g、h、js、j、k、m、n、p、r、s、t、u、v、x、y、z、za、zb、zc

常用基本偏差：
- **H**（孔）/ **h**（轴）：基准件，偏差为零
- **G**（孔）/ **g**（轴）：间隙配合
- **K**（孔）/ **k**（轴）：过渡配合
- **P**（孔）/ **p**（轴）：过盈配合

### 配合制度

📚 来源：GB/T 1800.1-2020 第6章

**基孔制**：孔的基本偏差固定为 H（下偏差为零），通过改变轴的偏差来获得不同配合

```
φ50H7/g6  →  间隙配合
φ50H7/k6  →  过渡配合
φ50H7/p6  →  过盈配合
```

**基轴制**：轴的基本偏差固定为 h（上偏差为零），通过改变孔的偏差来获得不同配合

```
φ50G7/h6  →  间隙配合
φ50K7/h6  →  过渡配合
φ50P7/h6  →  过盈配合
```

### 三种配合类型

| 配合类型 | 特征 | 应用 |
|----------|------|------|
| 间隙配合 | 孔的尺寸 > 轴的尺寸，总有间隙 | 滑动轴承、导轨 |
| 过渡配合 | 可能有间隙也可能有过盈 | 定位销、齿轮与轴 |
| 过盈配合 | 孔的尺寸 < 轴的尺寸，需压入 | 轴承与轴、齿轮与轴 |

### 形位公差

📚 来源：GB/T 1182-2018

形位公差包括形状公差和位置公差：

**形状公差**：
| 项目 | 符号 | 说明 |
|------|------|------|
| 直线度 | ─ | 实际直线对理想直线的偏离 |
| 平面度 | ⬜ | 实际平面对理想平面的偏离 |
| 圆度 | ○ | 实际圆对理想圆的偏离 |
| 圆柱度 | ⬭ | 实际圆柱面对理想圆柱面的偏离 |

**位置公差**：
| 项目 | 符号 | 说明 |
|------|------|------|
| 平行度 | ∥ | 两平面/轴线的平行程度 |
| 垂直度 | ⊥ | 两平面/轴线的垂直程度 |
| 同轴度 | ◎ | 两轴线的同轴程度 |
| 对称度 | ≡ | 两要素的对称程度 |
| 位置度 | ⊕ | 实际位置相对于理想位置的偏离 |

## 常见问题

1. **如何看懂公差标注 φ50H7**
   - φ50：基本尺寸 50mm
   - H：基本偏差代号（孔，下偏差为 0）
   - 7：公差等级 IT7
   - 查表可得：φ50H7 = φ50(+0.025/0)

2. **基孔制和基轴制如何选择**
   - 一般优先选用基孔制（孔的加工成本高于轴）
   - 冷拉钢轴等标准件采用基轴制

3. **数控加工如何保证公差**
   - 合理选择切削参数，避免让刀和振动
   - 使用刀具补偿功能
   - 精加工时留适当的余量
   - 加工后及时测量，必要时调整程序

## 总结

- 公差表示零件尺寸允许的变动范围，是保证互换性的基础
- 标准公差等级 IT01-IT18，精度从高到低
- 基孔制（H）和基轴制（h）是两种基准制度
- 配合分为间隙、过渡、过盈三种类型
- 形位公差控制零件的形状和位置精度
