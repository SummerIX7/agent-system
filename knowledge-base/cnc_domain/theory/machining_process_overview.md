# 加工流程认知

## 适用岗位

适用于操机工、调机工和编程师的入门学习。操机工需要理解“图纸到零件”的基本顺序，调机工需要掌握调试与首件确认的位置，编程师需要把工艺路线、程序、刀具和检验要求统一起来。

## 学习目标

1. 能说清数控加工从图纸评审到批量生产的主要步骤。
2. 能区分工艺分析、程序编制、对刀调试、首件检验和过程巡检的职责。
3. 能识别加工前必须准备的文件、刀具、夹具、量具和安全条件。
4. 能理解为什么必须先验证程序，再进入正式切削。

## 核心知识点

### 标准加工闭环

📚 来源：《数控加工工艺与实训》(周建平, 2022) 第1章

典型数控加工流程为：

```text
零件图纸评审 → 工艺分析 → 毛坯与基准确定 → 刀具夹具准备
→ 程序编制/导入 → 程序校验 → 装夹找正 → 对刀与设定坐标系
→ 空运行/单段试切 → 首件检验 → 参数修正 → 批量加工
→ 过程巡检 → 末件检验 → 记录归档
```

其中“程序校验、对刀、首件检验”是防止撞刀、尺寸超差和批量报废的关键节点。任何未经验证的程序都不能直接进入自动循环。

### 角色职责

| 岗位 | 重点职责 | 输出物 |
|------|----------|--------|
| 操机工 | 装夹、启停、换刀、巡检、安全确认 | 操作记录、尺寸记录 |
| 调机工 | 对刀、补偿、试切、首件调整 | 首件确认单、偏置记录 |
| 编程师 | 工艺路线、程序、刀具路径、工艺文件 | NC 程序、工艺卡、刀具清单 |

操机工遇到程序异常、刀具异常、尺寸连续偏移时应暂停并上报；调机工负责判断是补偿问题、装夹问题、刀具磨损还是程序问题；编程师负责从工艺和程序层面修正根因。

### 加工前准备

加工前至少确认四类资料：零件图、工艺卡、NC 程序、检验要求。至少准备四类实物：毛坯、刀具、夹具、量具。若缺少任一项，应先完成确认，不应靠经验“边做边猜”。

## 操作流程 / 编程示例

以加工一个带孔铝合金板件为例：

```text
1. 阅读图纸：确认外形尺寸、孔径、孔距、公差和表面粗糙度。
2. 确定基准：选择底面和相邻两边作为定位基准。
3. 制定路线：粗铣外形 → 精铣外形 → 钻中心孔 → 钻孔 → 倒角。
4. 准备刀具：面铣刀、立铣刀、中心钻、麻花钻、倒角刀。
5. 编制程序：设置 G54 工件坐标系，按工序调用刀具。
6. 验证程序：图形模拟、空运行、单段执行。
7. 首件测量：测外形、孔径、孔距，必要时修正刀补。
8. 批量加工：按巡检频次记录尺寸趋势。
```

## 检查表 / 参数表

| 检查项 | 合格标准 | 责任人 |
|--------|----------|--------|
| 程序号 | 与工艺卡一致 | 编程师/调机工 |
| 毛坯方向 | 与装夹图一致 | 操机工 |
| 工件坐标系 | G54-G59 与程序一致 | 调机工 |
| 刀具号 | T 号、H 号、D 号对应 | 调机工 |
| 量具 | 精度满足公差要求 | 操机工 |
| 首件 | 尺寸和外观合格 | 调机工/质检 |

## 常见错误与纠偏

1. **跳过空运行**：可能导致撞刀。纠偏：新程序必须先图形模拟，再空运行，最后单段试切。
2. **程序号和零件号不一致**：容易加工错件。纠偏：执行程序前读出程序名、版本和修改日期。
3. **只看尺寸不看毛刺和表面**：会导致外观不合格。纠偏：首件检验同时记录尺寸、倒角、毛刺和粗糙度。
4. **补偿修改无记录**：批量生产中难以追溯。纠偏：每次修改刀补都记录原因、数值和时间。
