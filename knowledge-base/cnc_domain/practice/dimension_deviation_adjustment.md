# 尺寸超差分析与调整

## 适用岗位

适用于调机工核心能力训练，也适合操机工理解什么时候应暂停上报。尺寸超差调整应基于测量数据和原因分析，不能凭感觉随意改刀补。

## 学习目标

1. 能区分系统性偏差、随机偏差和趋势性偏差。
2. 能从对刀、刀补、装夹、刀具磨损、热变形、程序和测量方法排查尺寸问题。
3. 能安全地进行刀补调整并验证。
4. 能记录调整闭环。

## 核心知识点

### 偏差类型

📚 来源：《机械加工质量控制》(周华, 2021) 第5章

| 类型 | 表现 | 常见原因 |
|------|------|----------|
| 系统性偏差 | 全部同方向偏大或偏小 | 对刀、刀补、坐标系、程序 |
| 随机偏差 | 无规律波动 | 装夹不稳、测量误差、毛坯不一致 |
| 趋势性偏差 | 随件数逐步漂移 | 刀具磨损、热变形、冷却变化 |
| 局部偏差 | 某个面或孔异常 | 刀路、夹具干涉、局部刚性 |

### 调整原则

先确认测量可靠，再确认装夹和刀具，最后修改补偿或程序。刀补调整要小步、可逆、有记录。若原因不明，不应连续多次盲目补偿。

### 直径与半径

车床 X 轴常按直径编程。外径偏差 0.04mm 时，补偿数值可能按直径调整 0.04mm，也可能按半径调整 0.02mm，取决于系统设置和补偿栏定义。调机工必须确认机床规则。

## 操作流程 / 编程示例

尺寸偏大处理流程：

```text
1. 复测尺寸，确认量具、温度、毛刺和测量位置。
2. 判断偏差是否超出公差，是否连续出现。
3. 检查刀具磨损、刀尖崩刃和夹紧状态。
4. 检查工件是否贴合基准，夹紧是否变形。
5. 检查刀补、坐标系和程序版本。
6. 选择调整方式：磨耗补偿、重新对刀、换刀或改程序。
7. 小幅调整后加工验证件，记录结果。
```

外圆调整示例：

```text
图纸要求：Φ40.00 ±0.02
实测：Φ40.05，超上差 0.03
判断：外径偏大，需要多切材料。
处理：检查刀具后，按机床直径补偿规则调整 X 向磨耗 -0.05 或对应方向。
验证：加工下一件并测量，目标靠近 Φ40.00。
```

内孔偏小示例：内孔偏小也需要多切材料，但补偿方向与外圆不同，应结合刀具路径和系统补偿方向确认。

## 检查表 / 参数表

| 检查项 | 判断问题 |
|--------|----------|
| 量具零位 | 排除测量误差 |
| 毛刺清理 | 避免假性偏大 |
| 连续件记录 | 判断趋势 |
| 刀具状态 | 磨损或崩刃 |
| 装夹状态 | 变形或未贴合 |
| 刀补记录 | 是否被误改 |

## 常见错误与纠偏

1. **未复测就改补偿**：可能把合格件改坏。纠偏：至少复测一次关键尺寸。
2. **外径和内孔同向调整**：方向可能相反。纠偏：画出刀具中心和材料去除方向。
3. **忽略热变形**：刚开机和连续加工尺寸不同。纠偏：预热并记录趋势。
4. **补偿后不记录**：交接班失控。纠偏：记录调整值、原因和验证尺寸。

## 练习题

2. 为什么尺寸超差分析要先复测？
3. 外径偏大和内孔偏小都表示什么加工状态？

## 来源与适用边界

本文用于尺寸调整培训。实际补偿正负方向和半径/直径规则必须按机床系统说明和现场验证执行。
