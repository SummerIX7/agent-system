# 加工仿真与碰撞检查

## 适用岗位

适用于编程师、调机工和工艺审核人员。仿真不是演示动画，而是验证刀具路径、材料去除、夹具避让和机床运动安全的重要手段。

## 学习目标

1. 区分刀路仿真、实体仿真和机床级仿真。
2. 能设置毛坯、工件、刀具、刀柄、夹具和安全边界。
3. 能检查过切、欠切、碰撞、残料和超行程。
4. 能把仿真问题反馈到 CAM 参数和工艺文件。

## 核心知识点

### 仿真类型

📚 来源：《CAM 加工仿真技术》(马志远, 2022) 第2章

| 类型 | 作用 | 局限 |
|------|------|------|
| 刀路仿真 | 看刀具中心轨迹 | 不一定显示实体干涉 |
| 实体仿真 | 模拟材料去除 | 需准确毛坯和刀具 |
| 机床级仿真 | 模拟机床轴运动 | 建模复杂，需后处理匹配 |
| 程序反读仿真 | 读取 NC 代码验证 | 依赖系统语法解析 |

### 碰撞对象

碰撞检查不只看刀尖。应检查刀具刃部、刀柄、夹头、主轴鼻端、工件、毛坯、压板、虎钳、转台、尾座和机床行程。多轴加工尤其要检查旋转轴摆动时的夹具干涉。

### 过切与欠切

过切是切除了不该切的材料，通常由刀具半径、边界、补偿、曲面方向或刀轴控制错误造成。欠切是残留过多材料，可能来自刀具直径过大、清角不足或加工区域遗漏。

## 操作流程 / 编程示例

仿真检查流程：

```text
1. 导入零件模型和毛坯模型。
2. 建立真实夹具、压板、刀具、刀柄和安全边界。
3. 按工序加载刀路，设置正确的刀具长度和直径。
4. 执行实体仿真，检查过切、残料和表面状态。
5. 执行碰撞检查，包含刀柄和夹具。
6. 后处理输出 NC 程序，再进行程序反读或机床图形验证。
7. 输出问题清单，回到 CAM 修改参数。
8. 保存仿真截图和版本记录，作为工艺审核证据。
```

问题记录示例：

```text
问题：T04 球刀精加工侧壁时刀柄与压板最小距离 1.2mm。
措施：压板外移 8mm，安全边界增加 5mm，刀具伸出增加 3mm。
验证：重新仿真无碰撞，最小间隙 6.5mm。
```

## 检查表 / 参数表

| 检查项 | 要求 |
|--------|------|
| 毛坯 | 尺寸和装夹方向正确 |
| 夹具 | 包含压板、螺栓、虎钳、定位块 |
| 刀具 | 直径、刃长、总长、刀柄正确 |
| 边界 | 加工区域和避让区域明确 |
| 余量 | 粗/精留量符合工艺 |
| NC 程序 | 后处理后再验证关键段 |

## 常见错误与纠偏

1. **只仿真零件不建夹具**：夹具碰撞遗漏。纠偏：建立简化但包络准确的夹具模型。
2. **仿真刀具长度与现场不一致**：结果失真。纠偏：刀具清单与 CAM 刀库同步。
3. **只看 CAM 刀路不看后处理程序**：后处理错误遗漏。纠偏：反读 NC 或机床图形验证。
4. **忽略快速移动碰撞**：非切削段撞夹具。纠偏：启用全路径碰撞检查。

## 来源与适用边界

本文用于仿真检查培训。仿真不能完全替代现场空运行和首件试切；最终加工安全仍需结合机床实际状态验证。
