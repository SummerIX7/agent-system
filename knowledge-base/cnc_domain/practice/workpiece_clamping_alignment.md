# 工件装夹与找正

## 适用岗位

适用于操机工和调机工。装夹与找正决定工件在机床上的真实位置，是坐标系设定、尺寸稳定和安全切削的基础。

## 学习目标

1. 理解六点定位、基准贴合和夹紧力方向。
2. 能完成虎钳、压板、三爪卡盘、专用夹具的基础装夹。
3. 能用百分表、寻边器、试切法进行找正。
4. 能识别装夹变形、基准脏污和夹紧不足导致的问题。

## 核心知识点

### 定位与夹紧

📚 来源：《数控加工工艺与夹具》(王先逵, 2021) 第3章

定位用于确定工件位置，夹紧用于保持工件位置。定位不等于夹紧，夹紧力应指向定位基准或支承点，避免把工件拉离基准。装夹前必须清理定位面和夹具接触面，切屑夹在基准面上会造成整体尺寸偏移和形位误差。

### 常见装夹方式

| 方式 | 适用零件 | 注意事项 |
|------|----------|----------|
| 虎钳装夹 | 小型方块、板件 | 平行垫铁支撑，敲实贴合 |
| 压板装夹 | 大板件、异形件 | 压板高度合理，防止翘曲 |
| 三爪卡盘 | 轴类、盘类 | 夹持长度足够，注意跳动 |
| 四爪单动 | 偏心件、非圆件 | 需逐爪找正 |
| 专用夹具 | 批量零件 | 定位销和压紧机构定期检查 |

### 找正方法

百分表找正用于检查直线边、圆柱外圆和夹具基准。寻边器适合建立工件坐标系。试切法常用于车床对 X/Z 基准或加工中心确认 Z 高度。

## 操作流程 / 编程示例

虎钳装夹板件流程：

```text
1. 清洁虎钳钳口、平行垫铁和工件底面。
2. 放入垫铁，工件靠紧固定钳口。
3. 轻夹后用铜棒或软锤敲击，使工件贴实垫铁。
4. 夹紧后用百分表扫上表面和侧边，确认平行度。
5. 用寻边器找 X/Y 零点，输入 G54。
6. 用对刀仪或试切法设定 Z 零点。
7. 首件加工后复测基准相关尺寸。
```

圆柱件三爪装夹流程：

```text
1. 检查卡盘爪是否清洁，夹持面无毛刺。
2. 工件伸出长度控制在满足加工但不降低刚性的范围内。
3. 夹紧后低速旋转观察跳动。
4. 用百分表测外圆跳动，必要时调整或重新装夹。
5. 长轴件使用尾座或中心架支撑。
```

## 检查表 / 参数表

| 检查项 | 合格要求 |
|--------|----------|
| 定位面 | 无切屑、毛刺、油泥 |
| 夹紧力 | 可靠但不使工件变形 |
| 工件伸出 | 不过长，避免振动 |
| 找正误差 | 满足工艺要求 |
| 坐标系 | G54-G59 与程序一致 |
| 干涉 | 刀具、夹具、压板避让充分 |

## 常见错误与纠偏

1. **基准面有切屑**：工件歪斜。纠偏：装夹前清洁并用手感确认贴合。
2. **压板悬空压紧**：夹紧不可靠。纠偏：压板支点高度接近工件受力点。
3. **坐标系设在错误角点**：程序整体偏移。纠偏：核对图纸基准和程序原点。
4. **夹紧过大导致薄壁变形**：松夹后尺寸变化。纠偏：增加支撑、软爪或分步加工。
