# 机床启停与急停

## 适用岗位

适用于操机工入门培训，也是调机工带教新员工时必须确认的基础技能。启停流程看似简单，但错误的上电、回零、暂停和急停操作会造成程序中断、刀具损坏甚至人身风险。

## 学习目标

1. 掌握开机、回零、预热、装夹确认、自动运行和关机顺序。
2. 区分进给保持、循环停止、复位和急停的使用场景。
3. 能在异常声音、碰撞风险、冷却失效等情况下做出安全停机。
4. 能完成停机后的状态恢复和记录。

## 核心知识点

### 开机基本顺序

📚 来源：《数控机床操作与维护》(刘战术, 2022) 第2章

```text
检查现场 → 合上总电源 → 释放急停 → 启动 CNC/液压/气源
→ 回参考点 → 主轴低速预热 → 检查润滑和冷却
→ 装夹工件 → 调入程序 → 空运行/单段 → 自动加工
```

回参考点用于建立机床坐标基准。未回零时不能直接运行依赖机床坐标或换刀位置的程序。

### 停止方式区别

| 操作 | 作用 | 典型场景 |
|------|------|----------|
| 进给保持 | 暂停进给，主轴通常继续转 | 观察切削、确认尺寸趋势 |
| 循环停止 | 停止自动循环 | 程序段结束后暂停 |
| 复位 RESET | 清除当前执行状态 | 程序报警、准备重新运行 |
| 急停 | 切断危险运动 | 撞刀、夹具松动、人身风险 |

急停是最后保护手段，不应作为普通暂停按钮使用。急停后需查明原因，确认刀具、夹具、工件和坐标状态，再恢复。

## 操作流程 / 编程示例

安全启动流程：

```text
1. 清理工作台，确认无扳手、量具、垫块遗留。
2. 检查防护门、急停按钮、气压、液压、润滑油和切削液。
3. 上电后先观察报警信息，异常未处理前不运行程序。
4. 执行回零，确认 X/Y/Z 轴参考点完成。
5. 主轴低速运行 5-10 分钟，观察异响和温升。
6. 调入程序并核对程序号、零件号和版本。
7. 用图形模拟、空运行和单段执行验证第一刀。
```

停机流程：

```text
1. 程序结束后确认主轴停止、冷却关闭、各轴在安全位置。
2. 取下工件并清理切屑，不用手直接触碰锋利切屑。
3. 清洁工作台、夹具和导轨防护。
4. 记录产量、异常、刀具更换和尺寸趋势。
5. 关闭液压/气源/电源，按现场制度交接。
```

## 检查表 / 参数表

| 检查项 | 合格要求 |
|--------|----------|
| 急停按钮 | 按下有效，释放后能复位 |
| 防护门 | 联锁有效，无人为屏蔽 |
| 气压/液压 | 达到设备要求范围 |
| 润滑 | 油位正常，报警消除 |
| 回零 | 各轴参考点完成 |
| 程序 | 程序号、刀具号、工件坐标系确认 |

## 常见错误与纠偏

1. **未取出扳手就开机**：可能甩出伤人。纠偏：启动前执行工作台清点。
2. **未回零直接换刀**：换刀位置不可靠。纠偏：上电后先回参考点。
3. **用 RESET 代替正常暂停**：可能丢失程序状态。纠偏：观察时优先用进给保持。
4. **急停后立即重启**：未排除根因。纠偏：急停后必须检查刀具、夹具、坐标和报警记录。

## 练习题

1. 进给保持和急停的区别是什么？
2. 为什么开机后要回参考点？
3. 急停后恢复加工前至少应确认哪些事项？

## 来源与适用边界

本文用于通用 CNC 启停培训。不同机床面板名称和联锁逻辑可能不同，实际操作以设备说明书和企业安全规程为准。
