# 换型调试流程

## 适用岗位

适用于调机工、班组长和操机工。换型调试是从上一种零件切换到下一种零件的过程，目标是在安全前提下缩短停机时间并保证首件合格。

## 学习目标

1. 掌握换型前、换型中、换型后的检查内容。
2. 能准备程序、夹具、刀具、量具、毛坯和检验文件。
3. 能理解 SMED 思想中内换型和外换型的区别。
4. 能通过清单减少漏项。

## 核心知识点

### 换型阶段

📚 来源：《数控生产现场管理》(孙立新, 2020) 第4章

```text
外部准备 → 停机拆卸 → 清洁检查 → 安装夹具/刀具
→ 调入程序 → 对刀找正 → 空运行 → 首件加工
→ 首件检验 → 批量放行 → 换型总结
```

外部准备指机床不停机时可完成的工作，如准备毛坯、量具、刀具、程序和工艺文件。内部换型指必须停机才能完成的工作，如拆装夹具和对刀。缩短换型时间的重点是把可提前完成的工作尽量外部化。

### 换型资料

换型资料包括：零件图纸、工艺卡、程序清单、刀具清单、夹具装配图、首件检验表、特殊注意事项和历史问题记录。

## 操作流程 / 编程示例

换型流程：

```text
1. 接收生产任务，确认零件号、版本、数量和交期。
2. 提前准备毛坯、刀具、夹具、量具和程序。
3. 上一批结束后清理机床，保存必要的生产记录。
4. 拆卸旧夹具，检查工作台和定位面。
5. 安装新夹具，按定位销、压板、螺栓顺序紧固。
6. 装入新刀具，核对 T/H/D 和刀具伸出。
7. 调入程序，核对程序号和工件坐标系。
8. 对刀找正，空运行和单段执行关键段。
9. 加工首件并按检验表测量。
10. 首件合格后放行，记录换型时间和异常。
```

换型记录示例：

```text
零件：A 切换至 B
开始：09:10，结束：10:05
主要耗时：夹具安装 20min，对刀 15min，首件检验 10min
异常：T03 刀片库存不足，已补充安全库存
```

## 检查表 / 参数表

| 阶段 | 检查项 |
|------|--------|
| 换型前 | 图纸版本、程序、刀具、夹具、量具、毛坯 |
| 拆卸 | 清洁、旧夹具归位、工装状态 |
| 安装 | 定位销、压板、扭矩、干涉 |
| 调试 | 坐标系、刀补、空运行、单段 |
| 首件 | 尺寸、外观、记录、放行 |
| 总结 | 换型时间、问题、改善措施 |

## 常见错误与纠偏

1. **停机后才找刀具**：换型时间长。纠偏：外部准备刀具包。
2. **夹具未清洁直接安装**：定位误差。纠偏：安装前清洁定位面。
3. **沿用旧坐标系**：整体偏移。纠偏：换型必须复核 G54-G59。
4. **首件未签字就批量**：质量风险。纠偏：执行首件放行制度。
