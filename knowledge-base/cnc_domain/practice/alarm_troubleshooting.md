# 常见报警处理

## 适用岗位

适用于操机工初步判断和调机工现场排查。报警处理的目标不是简单按复位消除，而是理解报警来源，避免带故障继续运行。

## 学习目标

1. 能区分操作报警、程序报警、伺服报警、主轴报警、气压液压报警和换刀报警。
2. 能按报警号、报警信息、发生时机和现场状态进行排查。
3. 能判断哪些报警可由操作人员处理，哪些必须通知维修。
4. 能记录报警和处理结果。

## 核心知识点

### 报警分类

📚 来源：《数控机床故障诊断与维护》(许建军, 2021) 第2章

| 类型 | 例子 | 常见处理 |
|------|------|----------|
| 操作报警 | 防护门未关、急停未释放 | 恢复操作条件 |
| 程序报警 | 格式错误、超行程、补偿错误 | 检查程序段 |
| 伺服报警 | 过载、跟随误差 | 停机检查轴负载 |
| 主轴报警 | 过载、编码器异常 | 检查刀具和主轴 |
| 气压液压报警 | 压力不足 | 检查气源、油泵 |
| 换刀报警 | 刀库不到位、机械手异常 | 按换刀恢复流程 |

### 处理原则

先看报警号和信息，再看发生时机。若报警发生在换刀、快速移动、切削重负载或撞机后，应优先检查机械状态，不能反复复位。

### 报警记录

报警记录至少包括：时间、机床编号、报警号、报警信息、程序号、程序段、刀具号、工件状态、处理人、处理措施和验证结果。

## 操作流程 / 编程示例

报警处理流程：

```text
1. 按进给保持或急停保护现场，根据风险选择停机方式。
2. 读取报警号、报警文本和发生程序段。
3. 拍照或记录机床坐标、刀具号、工件状态。
4. 判断是否为操作条件：门、气压、液压、急停、润滑。
5. 判断是否为程序问题：超程、补偿、固定循环、坐标系。
6. 若涉及伺服、主轴、换刀机械故障，通知维修或班组长。
7. 排除后低倍率、单段恢复，不直接全速继续。
```

程序超程示例：

```text
现象：运行到 G00 X250. Y-120. 时报警超行程。
排查：确认工件坐标系是否正确，程序坐标是否超出机床行程，是否选错 G54/G55。
处理：不能简单改大软限位，应修正坐标系或程序。
```

固定循环报警示例：孔加工后若未取消 G80，后续定位可能被系统解释为继续钻孔，应检查循环段和取消段。

## 检查表 / 参数表

| 报警场景 | 重点检查 |
|----------|----------|
| 上电报警 | 急停、门锁、气压、润滑 |
| 换刀报警 | 刀套位置、机械手、主轴定向 |
| 切削中过载 | 刀具磨损、切深、进给、排屑 |
| 快速移动报警 | 坐标系、行程、夹具干涉 |
| 程序格式报警 | G/M 代码、括号、小数点、宏变量 |

## 常见错误与纠偏

1. **反复 RESET**：掩盖根因。纠偏：记录报警后按原因处理。
2. **撞机后继续加工**：可能损坏主轴和夹具。纠偏：撞机后检查几何精度和刀具。
3. **超程就改软限位**：风险极高。纠偏：先查坐标和程序。
4. **不记录报警**：故障重复出现。纠偏：建立报警台账。
