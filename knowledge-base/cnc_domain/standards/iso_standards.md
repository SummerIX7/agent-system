# ISO 标准

## 概述

ISO（国际标准化组织）制定的数控相关标准是全球通用的技术规范。其中 ISO 6983（G 代码）是数控编程最基础的国际标准，ISO 14649（STEP-NC）是新一代数控标准。

## 核心知识点

### ISO 6983 — G 代码标准

📚 来源：ISO 6983-1:2009

ISO 6983 是数控编程的基础国际标准，规定了 G 代码和 M 代码的格式和含义。

**与 GB/T 8870 的关系**：
- GB/T 8870 等同采用 ISO 6983
- 两者内容基本一致

**程序段格式**：
```
N___ G___ X___ Y___ Z___ F___ S___ T___ M___
```

**G 代码分组**：

| 组别 | G 代码 | 说明 |
|------|--------|------|
| 01（运动） | G00, G01, G02, G03 | 快速定位、直线插补、圆弧插补 |
| 02（平面） | G17, G18, G19 | XY、XZ、YZ 平面选择 |
| 06（单位） | G20, G21 | 英制、公制 |
| 09（固定循环） | G73-G89 | 各种固定循环 |
| 10（补偿） | G40-G44 | 刀具补偿 |
| 12（坐标系） | G53-G59 | 坐标系选择 |
| 13（坐标） | G90, G91 | 绝对/增量坐标 |
| 14（进给） | G94, G95 | 每分钟/每转进给 |

### ISO 14649 — STEP-NC

📚 来源：ISO 14649-1:2003

STEP-NC 是新一代数控标准，旨在替代传统的 G 代码编程。

**与传统 G 代码的区别**：

| 特征 | G 代码 (ISO 6983) | STEP-NC (ISO 14649) |
|------|-------------------|---------------------|
| 编程方式 | 刀具路径 | 加工特征和操作 |
| 信息量 | 低（只有运动指令） | 高（含几何、工艺信息） |
| 可读性 | 差（数字代码） | 好（面向对象描述） |
| 可移植性 | 差（依赖机床） | 好（机床无关） |
| 双向通信 | 不支持 | 支持 |

**STEP-NC 的优势**：
1. 包含完整的零件几何信息和加工工艺信息
2. 支持从 CAD/CAM 到 CNC 的无缝数据传递
3. 支持加工过程的实时监控和优化
4. 便于实现智能制造和数字孪生

### ISO 230 — 机床检验

📚 来源：ISO 230-1:2012

规定了数控机床精度检验的测试方法。

**主要检验项目**：
1. 定位精度：实际位置与指令位置的偏差
2. 重复定位精度：多次定位到同一位置的一致性
3. 反向间隙：反向运动时的空行程
4. 直线度：运动轨迹的直线度
5. 垂直度：两轴运动方向的垂直程度

**精度表示方法**：
```
定位精度：A = x̄ ± 3σ

x̄：平均定位偏差
3σ：3倍标准差（99.73%的置信区间）
```

### ISO 13399 — 刀具数据表示

📚 来源：ISO 13399-1:2006

规定了数控刀具数据的标准化表示方法，便于刀具信息的数字化管理。

**刀具数据分类**：
- 刀具整体信息（类型、尺寸、材料）
- 刀片信息（形状、材质、涂层）
- 刀杆信息（规格、夹持方式）
- 切削参数推荐

### ISO 10791 — 加工中心检验

📚 来源：ISO 10791-1:2015

规定了加工中心的检验条件和精度要求。

**检验项目**：
- 几何精度检验
- 定位精度检验
- 工作精度检验
- 温度变化对精度的影响

## 常见问题

1. **ISO 标准与 GB 标准的关系**
   - GB 标准通常等同或修改采用 ISO 标准
   - 两者技术内容基本一致
   - 国内执行优先参考 GB 标准

2. **STEP-NC 会取代 G 代码吗**
   - 短期内不会完全取代
   - STEP-NC 在航空航天等高端领域逐步应用
   - G 代码仍然是最广泛使用的编程方式

3. **数控编程必须了解哪些 ISO 标准**
   - ISO 6983（G 代码）：编程基础
   - ISO 230（机床检验）：理解精度指标
   - ISO 13399（刀具数据）：刀具管理

## 总结

- ISO 6983 是 G 代码的国际标准，与 GB/T 8870 等效
- ISO 14649（STEP-NC）是面向未来的数控标准
- ISO 230 规定了机床精度检验方法
- ISO 标准是全球通用的技术规范
