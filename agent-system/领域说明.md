# 领域说明：领域知识个性化生成与多智能体协同决策系统

## 系统概述

本系统面向数据分析领域的个性化学习场景，通过 6 个 AI Agent 协同工作，为不同水平的学习者自动生成定制化的学习资源。

## 核心功能

- **学情诊断**：基于学习者画像精准定位知识盲区，匹配适宜的学习难度
- **知识生成**：结合 RAG 知识库，自动生成讲义、实验指导和项目案例，并标注知识来源
- **审核纠偏**：通过辩论机制（审核质疑 → 生成反驳 → 独立裁判）确保生成内容的准确性
- **动态调整**：根据学习者的答题反馈，实时调整学习路径和资源推荐

## 创新点

- 多智能体辩论与独立裁判机制，有效降低知识谬误率
- 知识溯源体系，每条知识点标注出处（书名、作者、章节）
- 基于学习者画像的难度自适应匹配，覆盖初级到专家四个等级
