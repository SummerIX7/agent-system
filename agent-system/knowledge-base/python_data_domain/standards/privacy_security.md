# 数据隐私与安全规范

## 概述

随着《个人信息保护法》《数据安全法》的全面实施，数据隐私与安全已成为数据分析工作的刚性约束。本规范旨在指导Python数据分析项目在合法合规的前提下开展数据处理活动，涵盖数据脱敏、加密存储、访问控制和合规审计等关键环节。数据分析人员必须树立"隐私优先"的理念，在数据采集、处理、共享的全过程中落实安全保护措施，防范数据泄露、滥用和非法访问风险，确保个人隐私权益和企业数据资产安全。

## 核心规范

### 数据脱敏（Data Masking）

对敏感个人信息实施脱敏处理，包括但不限于身份证号、手机号、银行卡号、姓名等。脱敏方式包括掩码、截断、替换、加密等，需根据业务场景选择合适的脱敏策略。

```python
import re

def mask_phone(phone):
    """手机号脱敏：保留前3后4"""
    if len(str(phone)) == 11:
        return str(phone)[:3] + '****' + str(phone)[7:]
    return phone

def mask_idcard(idcard):
    """身份证号脱敏：保留前4后4"""
    if len(str(idcard)) == 18:
        return str(idcard)[:4] + '**********' + str(idcard)[14:]
    return idcard
```

### 加密存储（Encryption）

敏感数据必须加密存储，推荐使用AES-256等对称加密算法。密钥管理应采用专用密钥管理系统，禁止在代码中硬编码密钥。数据库连接字符串、API密钥等配置信息应通过环境变量或配置中心管理。

### 合规要求（Compliance）

遵循GDPR、《个人信息保护法》等法规要求，落实"知情-同意"原则，明确数据处理目的和范围。建立数据分类分级制度，对不同敏感级别的数据实施差异化保护策略。跨境数据传输需进行安全评估。

### 访问控制（Access Control）

实施最小权限原则，按角色分配数据访问权限。敏感数据查询需记录审计日志，包括访问人、访问时间、访问内容等。定期review权限分配，及时回收离职人员权限。

## 检查清单

- [ ] 完成数据分类分级评估
- [ ] 对敏感字段实施脱敏处理
- [ ] 配置数据库加密和传输加密
- [ ] 建立数据访问审计日志
- [ ] 签署数据保密协议
- [ ] 定期开展安全培训和演练
- [ ] 建立数据泄露应急响应预案

## 案例说明

1. 正例：某银行数据分析团队在用户画像项目中，对所有PII字段实施脱敏处理，使用差分隐私技术保护个体信息，顺利通过监管合规审计，同时保持了分析模型的有效性。

2. 反例：某互联网公司数据分析师将包含用户手机号的分析结果直接分享至公共群聊，导致大规模用户信息泄露，公司被处以200万元罚款，相关责任人被追究法律责任。
