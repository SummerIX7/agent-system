# 数据质量标准规范

## 概述

数据质量是数据分析工作的基石，直接决定了分析结果的可靠性和决策的有效性。本规范基于GB/T 36344-2018《信息技术 数据质量评价指标》等国家标准，结合Python数据分析实践，定义了数据质量的四大核心维度：完整性、准确性、一致性和时效性。在数据驱动的业务环境中，高质量的数据能够降低决策风险，提升运营效率，而低质量的数据则可能导致错误的业务判断和资源浪费。数据质量管理应当贯穿数据采集、存储、处理、分析和应用的全生命周期。

## 核心规范

### 完整性（Completeness）

完整性要求数据记录无缺失，字段值齐全。在Python数据分析中，需要检查关键字段的空值率，一般要求核心字段空值率不超过5%，辅助字段空值率不超过15%。

```python
import pandas as pd

def check_completeness(df, key_columns):
    """检查数据完整性"""
    missing_rate = df[key_columns].isnull().sum() / len(df)
    return missing_rate[missing_rate > 0.05]
```

### 准确性（Accuracy）

准确性要求数据值真实反映客观事实。需要建立数据校验规则，包括范围检查、格式检查、逻辑检查等。数值型数据应设定合理的取值范围，文本型数据应符合预定义的格式规范。

### 一致性（Consistency）

一致性要求同一数据在不同系统、不同时间点保持一致。需要统一数据编码标准、度量单位和命名规范。跨表关联时，主外键关系必须完整有效。

### 时效性（Timeliness）

时效性要求数据在规定时间内更新并可获取。实时分析场景要求数据延迟不超过分钟级，批量分析场景要求数据更新周期明确且可预期。

## 检查清单

- [ ] 建立数据质量监控指标体系
- [ ] 实施数据采集阶段的格式校验
- [ ] 配置空值率、异常值自动告警
- [ ] 定期执行数据一致性比对
- [ ] 记录数据质量问题及处理日志
- [ ] 建立数据质量评分卡机制
- [ ] 制定数据修复和补全流程

## 案例说明

1. 正例：某电商平台建立订单数据质量监控，实时检测金额字段的范围异常和必填字段缺失，数据质量评分从82分提升至96分，退货率分析准确性提高30%。

2. 反例：某金融机构未对客户年龄字段做范围校验，导致部分记录年龄为负数或超过150岁，用户画像分析结果严重失真，营销活动ROI下降40%。
