# 数据分析行业规范与最佳实践

## 数据处理规范

### 数据质量标准

1. **完整性**：关键字段缺失率应 < 5%
2. **准确性**：数据值应在合理范围内
3. **一致性**：同一实体在不同表中的表示应一致
4. **时效性**：数据应反映当前状态

### 数据命名规范

```python
# 表名：小写下划线
user_behavior     # ✓
UserBehavior      # ✗

# 列名：小写下划线
created_at        # ✓
createdAt         # ✗
CreatedAt         # ✗

# 分类值：小写
gender: 'male', 'female'    # ✓
gender: 'Male', 'Female'    # ✗
```

### 缺失值处理规范

| 缺失比例 | 处理方式 |
|----------|----------|
| < 5% | 可删除或均值/中位数填充 |
| 5% - 30% | 使用模型预测填充或标记为特殊值 |
| > 30% | 考虑删除该特征，或作为单独类别 |

### 异常值处理规范

1. **先判断是否为真实数据**：极端值可能是真实的业务现象
2. **使用统计方法检测**：IQR 法、Z-score 法
3. **记录处理决策**：说明为什么删除或保留

## 可视化规范

### 图表选择指南

| 分析目的 | 推荐图表 |
|----------|----------|
| 展示趋势 | 折线图 |
| 比较大小 | 柱状图 |
| 展示占比 | 饼图（≤5类）/ 堆叠柱状图 |
| 展示分布 | 直方图 / 箱线图 |
| 展示相关性 | 散点图 / 热力图 |
| 展示地理分布 | 地图 |

### 图表设计原则

1. **标题清晰**：图表标题应说明"什么数据 + 什么维度 + 什么时间"
2. **坐标轴标签**：必须有轴标签和单位
3. **图例位置**：不遮挡数据
4. **颜色使用**：不超过 7 种颜色，使用色盲友好的配色
5. **数据标注**：关键数据点应有数值标注

### 常见错误

1. **Y 轴不从 0 开始**：夸大差异
2. **3D 饼图**：增加阅读难度
3. **过多分类**：饼图分类超过 5 个
4. **缺少数据来源**：图表应标注数据来源

## 报告撰写规范

### 分析报告结构

1. **执行摘要**：1-2 页，面向管理层
2. **背景与目标**：为什么做这个分析
3. **数据说明**：数据来源、时间范围、关键指标定义
4. **分析过程**：方法论和关键步骤
5. **发现与结论**：用数据支撑的发现
6. **建议与行动**：基于发现的可执行建议
7. **附录**：详细数据表格、技术细节

### 写作原则

1. **结论先行**：先说结论，再展开分析
2. **数据支撑**：每个结论都要有数据依据
3. **避免主观判断**：用"数据显示"而非"我认为"
4. **可操作性**：建议应具体、可执行
