# 数据可视化最佳实践规范

## 概述

数据可视化是将复杂数据转化为直观图形的关键技术，优秀的可视化设计能够帮助决策者快速理解数据洞察，提升沟通效率。本规范基于可视化设计理论和Python数据分析实践（Matplotlib、Seaborn、Plotly等库），定义了图表选择、颜色使用、标注规范等核心要素。良好的可视化应当做到准确传达数据信息、避免误导、美观专业、易于理解。数据分析人员需要根据数据类型、分析目的和受众特点，选择最合适的可视化方案。

## 核心规范

### 图表选择（Chart Selection）

根据数据关系类型选择合适的图表：

| 数据关系 | 推荐图表 | 适用场景 |
|---------|---------|---------|
| 趋势变化 | 折线图、面积图 | 时间序列数据 |
| 大小比较 | 柱状图、条形图 | 分类数据对比 |
| 占比构成 | 饼图、堆叠图 | 比例关系展示 |
| 分布规律 | 直方图、箱线图 | 数据分布特征 |
| 相关关系 | 散点图、气泡图 | 变量关联分析 |

```python
import matplotlib.pyplot as plt
import seaborn as sns

# 设置中文字体支持
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 趋势分析使用折线图
def plot_trend(df, x_col, y_col, title):
    fig, ax = plt.subplots(figsize=(10, 6))
    ax.plot(df[x_col], df[y_col], marker='o', linewidth=2)
    ax.set_title(title, fontsize=14, fontweight='bold')
    ax.grid(True, alpha=0.3)
    return fig
```

### 颜色使用（Color Usage）

遵循色彩设计原则，使用有意义的颜色编码。分类数据使用离散色板，连续数据使用渐变色板。注意色盲友好设计，避免仅依赖红绿区分。推荐使用Seaborn的colorblind调色板。

### 标注规范（Annotation Standards）

图表必须包含清晰的标题、坐标轴标签、图例和数据来源。数值标签应保留适当精度，避免过度精确。关键数据点需要突出标注，添加解释性文字说明。

### 布局设计（Layout Design）

保持图表简洁，移除不必要的装饰元素。合理设置图表尺寸和分辨率，屏幕展示推荐1920x1080，打印输出推荐300DPI。多图表组合时保持风格统一。

## 案例说明

1. 正例：某零售企业使用堆叠柱状图展示各品类销售额占比变化，配合动态筛选功能，管理层能够直观识别增长品类和下滑品类，季度经营分析效率提升50%。

2. 反例：某分析师使用3D饼图展示市场份额，由于透视变形导致占比判断失真，且使用了相近的颜色区分细分市场，决策者无法准确识别各竞争对手份额，误导了市场策略制定。
