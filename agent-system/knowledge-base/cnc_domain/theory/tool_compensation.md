# 刀具补偿原理

## 适用岗位

适用于调机工和编程师，也适合需要读懂程序的操机工。刀具补偿是把“理论刀位”和“实际刀具尺寸、磨损、安装误差”连接起来的关键机制。

## 学习目标

1. 理解刀具长度补偿、半径补偿和磨耗补偿的区别。
2. 能识别 G40/G41/G42、G43/G49、H/D 补偿号的作用。
3. 能解释为什么补偿必须配合安全引入和取消路径。
4. 能进行常见尺寸偏差的补偿判断。

## 核心知识点

### 补偿类型

📚 来源：《数控编程与操作》(张明, 2022) 第5章

| 补偿 | 常用指令 | 作用 |
|------|----------|------|
| 刀具长度补偿 | G43 Hxx / G49 | 补偿刀具 Z 向长度差异 |
| 刀具半径左补偿 | G41 Dxx | 刀具位于编程轮廓左侧 |
| 刀具半径右补偿 | G42 Dxx | 刀具位于编程轮廓右侧 |
| 取消半径补偿 | G40 | 取消 G41/G42 |
| 磨耗补偿 | 偏置表 Wear | 微调尺寸，补偿磨损 |

在加工中心中，T 号表示刀具号，H 号通常对应长度补偿，D 号通常对应半径补偿。常见规范是 T01 对应 H01、D01，但必须以现场刀具表为准。

### 左补偿和右补偿判断

沿刀具进给方向看，刀具中心在编程轮廓左侧为 G41，在右侧为 G42。外轮廓顺时针加工和逆时针加工所需补偿方向不同，不能只靠“外形一定用 G41”这样的经验判断。

### 补偿引入与取消

半径补偿需要引入段和取消段。引入段长度一般应大于刀具半径，并避免在尖角或已加工表面上直接建立补偿。取消补偿也应安排在离开轮廓后的安全位置。

## 操作流程 / 编程示例

加工中心外轮廓示例：

```gcode
%
O1201
G90 G21 G17 G40 G49 G80
T01 M06
S2500 M03
G54 G00 X-20. Y-10.
G43 H01 Z50.
Z5.
G01 Z-5. F120.
G41 D01 X0. Y0. F300.
X80.
Y40.
X0.
Y0.
G40 X-20. Y-10.
G00 Z50.
M30
%
```

说明：`G43 H01` 建立长度补偿；`G41 D01` 建立半径左补偿；`G40` 在离开轮廓后取消补偿。若 D01 半径值输入错误，轮廓尺寸会系统性偏大或偏小。

尺寸调整示例：

```text
外轮廓尺寸偏大 0.06mm：
- 若程序使用半径补偿加工外轮廓，可适当增大 D 磨耗补偿，使刀具中心远离轮廓。
- 若内腔尺寸偏小，通常也需要让刀具多切材料，但补偿方向要结合加工方向确认。
```

## 检查表 / 参数表

| 检查项 | 要点 |
|--------|------|
| H/D 号 | 是否与刀具号对应 |
| 补偿值 | 长度、半径、磨耗单位是否正确 |
| 引入段 | 长度是否足够，位置是否安全 |
| 取消段 | 是否在离开轮廓后取消 |
| 平面选择 | G17/G18/G19 是否与加工平面一致 |
| 模态状态 | 程序开头是否取消旧补偿 G40/G49 |

## 常见错误与纠偏

1. **H 号调用错误**：可能造成 Z 向撞刀。纠偏：换刀后核对 T、H、刀长表。
2. **D 值正负误用**：轮廓尺寸异常。纠偏：先小余量试切，测量后再放量。
3. **无引入段直接 G41/G42**：系统报警或刀路突变。纠偏：增加直线引入。
4. **忘记 G40**：后续刀路仍带补偿。纠偏：每个轮廓结束后在安全位置取消补偿。

## 来源与适用边界

本文说明 FANUC 类常见补偿思想。不同数控系统的补偿表、半径/直径补偿方式、报警规则可能不同，必须结合机床说明书验证。
