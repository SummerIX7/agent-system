# 四轴五轴编程基础

## 适用岗位

适用于编程师高级学习，也适合调机工了解多轴机床调试风险。四轴五轴加工能减少装夹次数、加工复杂曲面和空间孔，但对坐标系、后处理、碰撞检查要求更高。

## 学习目标

1. 理解三轴、四轴、五轴加工的区别。
2. 能识别 A/B/C 旋转轴和常见机床结构。
3. 能说明 3+2 定位加工与五轴联动加工的差异。
4. 能列出多轴编程前必须验证的安全项目。

## 核心知识点

### 旋转轴定义

📚 来源：《多轴数控加工技术》(陈刚, 2023) 第1章

根据右手坐标系，绕 X/Y/Z 轴旋转的轴通常称为 A/B/C 轴。四轴加工常见形式为三直线轴加一个旋转轴；五轴加工通常为三直线轴加两个旋转轴。

### 机床结构

| 结构 | 特点 | 适用场景 |
|------|------|----------|
| 转台式四轴 | 工件旋转，刀具三轴运动 | 轴类、圆周孔、侧面加工 |
| 摆头式五轴 | 主轴摆动，工件固定 | 大型零件、复杂曲面 |
| 转台摆头式五轴 | 工件和刀具均可转动 | 模具、叶轮、医疗零件 |
| 双转台式五轴 | 工作台两个旋转自由度 | 小型高精密零件 |

### 3+2 与五轴联动

3+2 定位加工是先把旋转轴转到指定角度并锁定，再按三轴方式加工；五轴联动是在切削过程中直线轴和旋转轴同时运动。3+2 更容易验证，适合多面体和斜孔；五轴联动适合叶轮、复杂曲面和避免刀具干涉的连续加工。

### 后处理重要性

多轴程序高度依赖后处理器。相同 CAM 刀路经过不同后处理，可能输出不同旋转轴方向、坐标转换方式和安全退刀动作。后处理必须与机床结构、控制系统、旋转中心和刀尖点控制功能匹配。

## 操作流程 / 编程示例

四轴圆周孔思路：

```gcode
G90 G54 G17 G40 G49 G80
T05 M06
S1200 M03
G43 H05 Z100.
A0.
G81 X0. Y0. Z-15. R2. F100.
A90.
G81 X0. Y0. Z-15. R2. F100.
A180.
G81 X0. Y0. Z-15. R2. F100.
A270.
G81 X0. Y0. Z-15. R2. F100.
G80
G00 Z100.
M30
```

该示例仅表达定位加工思想。实际四轴加工中，还要设置旋转轴中心、夹具避让和安全平面，不能直接套用。

五轴编程基本流程：

```text
导入模型 → 定义机床结构 → 设置毛坯和夹具 → 设置加工坐标系
→ 选择 3+2 或五轴联动策略 → 设置刀轴控制 → 生成刀路
→ 机床级仿真 → 碰撞检查 → 后处理 → 试运行
```

## 检查表 / 参数表

| 检查项 | 说明 |
|--------|------|
| 旋转中心 | CAM 与机床参数一致 |
| 刀尖点控制 | 是否启用 TCP/RTCP |
| 旋转限位 | A/B/C 轴角度不超行程 |
| 夹具模型 | 仿真中包含真实夹具 |
| 后处理 | 与机床和系统完全匹配 |
| 退刀动作 | 换面前先到安全位置 |

## 常见错误与纠偏

1. **只仿真刀路不仿真机床**：看不到摆头和夹具碰撞。纠偏：使用机床级仿真。
2. **旋转中心错误**：实际位置偏移。纠偏：校准旋转中心并同步 CAM 参数。
3. **后处理不匹配**：机床报警或运动反向。纠偏：使用经验证的后处理器。
4. **刀具过短或过长**：过短干涉，过长刚性差。纠偏：平衡避让和刚性。
