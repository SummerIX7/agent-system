# 常见加工缺陷识别

## 适用岗位

适用于操机工的异常识别、调机工的缺陷排查和编程师的工艺优化。学习者应能从声音、切屑、表面、尺寸趋势判断加工状态，而不是只在报废后才发现问题。

## 学习目标

1. 能识别尺寸超差、表面粗糙、振纹、毛刺、烧伤、崩边等常见缺陷。
2. 能把缺陷与刀具、参数、装夹、冷却、程序和材料因素对应起来。
3. 能给出首要排查顺序和临时纠偏措施。
4. 能理解缺陷记录对持续改进的重要性。

## 核心知识点

### 缺陷分类

📚 来源：《机械加工质量控制》(周华, 2021) 第4章

| 缺陷 | 典型表现 | 常见原因 |
|------|----------|----------|
| 尺寸超差 | 外径偏大/偏小，孔径不合格 | 对刀误差、刀补错误、刀具磨损、热变形 |
| 表面粗糙 | 刀纹明显、粗糙度 Ra 超标 | 进给过大、刀尖圆弧不合适、刀具磨损 |
| 振纹 | 表面周期性波纹 | 装夹刚性差、刀具伸出过长、参数过激 |
| 毛刺 | 边缘翻边、孔口毛刺 | 刀具不锋利、出口无支撑、倒角不足 |
| 烧伤 | 表面变色、硬化或裂纹 | 冷却不足、切削速度过高、磨削热大 |
| 崩边 | 边角破损 | 切入切出方式不当、材料脆、刀具冲击 |

### 尺寸趋势判断

单件尺寸超差不一定代表系统性问题，但连续多件同方向偏移通常说明刀具磨损、热变形或补偿设置不当。操机工应记录连续尺寸变化，调机工根据趋势决定是否调整刀补。

### 声音与切屑信号

正常切削声音应相对稳定，切屑形态应与材料和工序匹配。若出现尖叫、断续敲击、切屑发蓝、长卷屑缠刀等现象，应降低进给或暂停检查刀具、冷却和排屑。

## 操作流程 / 编程示例

发现缺陷后建议按“先安全、后定位、再修正”的顺序处理：

```text
1. 暂停自动循环，必要时按进给保持，不直接伸手清屑。
2. 保护现场，记录程序段、刀具号、工件序号和异常现象。
3. 测量关键尺寸，判断是单点异常还是连续趋势。
4. 检查刀具磨损、刀片夹紧、刀具伸出长度和冷却液状态。
5. 检查工件装夹、基准贴合、夹紧力和定位面清洁度。
6. 检查刀补、坐标系、程序版本和切削参数。
7. 小幅修正后重新试切，首件复测合格再恢复批量。
```

尺寸补偿示例：外圆车削后实测直径比图纸大 0.04mm，若 X 轴以直径编程并使用直径补偿，通常可将 X 向磨耗补偿减小 0.04mm；若系统按半径补偿，应按机床说明确认补偿方式，避免反向或倍数错误。

## 检查表 / 参数表

| 现象 | 优先检查 | 纠偏方向 |
|------|----------|----------|
| 外圆逐件变大 | 刀具磨损、刀补 | 调整磨耗补偿或换刀 |
| 孔位置整体偏移 | 坐标系、装夹基准 | 复查 G54 和找正 |
| 表面振纹 | 刀具伸出、夹紧刚性 | 缩短伸出、降低切深 |
| 毛刺严重 | 刀具锋利度、倒角工序 | 换刀或增加倒角 |
| 切屑发蓝 | 冷却、切削速度 | 增强冷却或降速 |

## 常见错误与纠偏

1. **只改程序不查刀具**：很多缺陷来自刀具磨损。应先检查实物状态。
2. **一次补偿过大**：可能造成反向超差。应小步调整并复测。
3. **未区分系统误差和随机误差**：单件异常可能来自装夹切屑。应清洁定位面后复测。
4. **缺陷不记录**：导致班组重复犯错。应形成缺陷、原因、措施、验证结果的闭环。

## 练习题

1. 铣削侧壁出现周期性振纹，至少列出三项可能原因。
2. 连续 5 件外径逐件变大，应优先判断为什么类型的问题？
3. 为什么缺陷分析不能只看最终尺寸？

## 来源与适用边界

本文用于培训缺陷识别和排查思路。具体补偿方向、参数极限和停机流程应以机床系统说明书、企业工艺规程和安全制度为准。
