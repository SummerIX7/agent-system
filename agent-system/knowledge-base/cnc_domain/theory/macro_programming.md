# B类宏程序编程

## 适用岗位

适用于编程师进阶学习，也适合调机工理解批量参数化加工程序。宏程序用于把重复、相似、可计算的刀路写成参数化逻辑，减少重复编程和手工改错。

## 学习目标

1. 理解变量、运算、条件判断和循环在数控程序中的用途。
2. 能读懂常见 FANUC B 类宏程序结构。
3. 能用宏程序实现孔阵列、倒角、简单轮廓重复加工。
4. 能识别宏程序带来的安全风险。

## 核心知识点

### 变量类型

📚 来源：《FANUC 数控宏程序应用》(赵国强, 2021) 第2章

| 变量 | 范围示例 | 用途 |
|------|----------|------|
| 局部变量 | #1-#33 | 宏调用参数，子程序内部使用 |
| 公共变量 | #100-#199 | 程序间共享，断电后可能清除 |
| 保持变量 | #500-#999 | 断电保持，用于长期参数 |
| 系统变量 | #1000 以上 | 机床状态、坐标、刀补等 |

变量使用前应明确初值。公共变量和保持变量不应随意占用，否则可能影响其他程序。

### 运算与条件

宏程序支持算术运算、三角函数、比较判断和跳转。常见语句包括：

```gcode
#100 = 10.0
#101 = #100 * 2
IF [#101 GT 15] GOTO 100
WHILE [#100 LT 50] DO1
  #100 = #100 + 5
END1
N100
```

### 宏调用

常见调用方式为 `G65 Pxxxx A_ B_ C_`，其中 P 指定宏程序号，A/B/C 等地址字传入局部变量。不同系统的地址字与局部变量映射可能存在差异，应以系统说明书为准。

## 操作流程 / 编程示例

圆周孔阵列宏程序示例，用于理解参数化思想：

```gcode
O9001 (BOLT CIRCLE DRILL)
(#1=半径R, #2=孔数N, #3=起始角A, #4=孔深Z)
#100 = 0
WHILE [#100 LT #2] DO1
  #101 = #3 + 360.0 / #2 * #100
  #102 = COS[#101] * #1
  #103 = SIN[#101] * #1
  G00 X#102 Y#103
  G81 Z#4 R2. F120.
  #100 = #100 + 1
END1
G80
M99
```

调用示例：

```gcode
G90 G54 G17 G40 G49 G80
T03 M06
S1800 M03
G43 H03 Z50.
G65 P9001 A30. B6. C0. Z-12.
M30
```

实际应用时，需确认 A/B/C/Z 地址是否映射到预期局部变量，并在首件前空运行验证每个孔位。

## 检查表 / 参数表

| 检查项 | 要点 |
|--------|------|
| 变量初值 | 是否赋值，是否继承旧值 |
| 循环终止 | WHILE 条件是否能结束 |
| 坐标单位 | 角度、长度、绝对/增量是否一致 |
| 安全高度 | 每次移动前是否退到安全 Z |
| 系统变量 | 是否避免误写系统关键参数 |
| 调用参数 | 调用时参数含义是否写入注释 |

## 常见错误与纠偏

1. **死循环**：循环变量未变化。纠偏：每个循环必须有明确递增/递减。
2. **变量残留**：公共变量沿用旧值。纠偏：程序开头初始化关键变量。
3. **角度单位误判**：三角函数结果错误。纠偏：确认系统三角函数使用角度还是弧度。
4. **无安全高度移动**：孔间移动刮伤工件。纠偏：每次快速定位前退刀。

## 来源与适用边界

本文用于宏程序原理教学。不同系统对变量范围、宏调用和系统变量定义不同，生产程序必须在对应机床上通过图形模拟、空运行和首件验证。
