# 坐标系与运动轴

## 概述

坐标系是数控编程的基础，正确理解和使用坐标系是编写正确加工程序的前提。数控机床涉及多种坐标系概念，包括机床坐标系、工件坐标系、绝对坐标和增量坐标等。本文详细讲解各坐标系的定义、建立方法和使用场景。

## 核心知识点

### 机床坐标系（Machine Coordinate System）

机床坐标系是数控机床固有的坐标系，由机床制造商在出厂时设定，用户不能更改。

📚 来源：《数控编程》(王爱玲, 2021) 第2章第1节

特点：
- 原点称为**机床原点（Machine Origin）**，通常设在各轴的正向极限位置
- 机床开机后必须执行**回参考点（回零）**操作来建立机床坐标系
- 机床坐标系是所有其他坐标系的基准

回参考点操作：
```gcode
; 开机后执行回参考点（手动操作，非程序指令）
; 机床自动移动到各轴的参考点位置
; 建立机床坐标系原点
```

### 工件坐标系（Workpiece Coordinate System）

工件坐标系是编程时使用的坐标系，以工件上的某一点为原点。

📚 来源：《数控编程》(王爱玲, 2021) 第2章第2节

特点：
- 原点称为**工件原点**，通常设在工件的设计基准上
- 编程时所有坐标值都相对于工件原点
- 通过 G54~G59 指令设定工件坐标系

工件原点的选择原则：
1. 便于编程和尺寸计算
2. 便于对刀操作
3. 通常选在工件的设计基准上

设定工件坐标系的方法：
```gcode
; 方法一：使用 G54~G59（预设工件坐标系）
; 在机床参数中设置 G54 的 X/Y/Z 值（工件原点相对于机床原点的偏移量）

; 方法二：使用 G92（设定当前点的坐标值）
G92 X0 Z0  ; 将当前刀具位置设定为工件原点

; 方法三：使用 G50（车床常用）
G50 X100 Z50  ; 设定工件坐标系原点
```

G54~G59 的使用：
```gcode
; 加工第一个工件（使用 G54）
G54 G00 X0 Z0  ; 移动到 G54 坐标系的原点

; 加工第二个工件（使用 G55）
G55 G00 X0 Z0  ; 移动到 G55 坐标系的原点
```

### 绝对坐标与增量坐标

📚 来源：《数控编程》(王爱玲, 2021) 第2章第3节

**绝对坐标编程（G90）**：所有坐标值都相对于工件原点

```gcode
; 绝对坐标编程
G90 G00 X50 Z30  ; 移动到 X50 Z30（相对于工件原点）
G01 X80 Z-20 F0.2  ; 直线切削到 X80 Z-20
```

**增量坐标编程（G91）**：坐标值相对于当前位置（增量值）

```gcode
; 增量坐标编程
G91 G00 X20 Z10  ; 从当前位置向 X 正方向移动 20，向 Z 正方向移动 10
G01 X30 Z-50 F0.2  ; 从当前位置向 X 正方向移动 30，向 Z 负方向移动 50
```

车床中的增量坐标表示：
- X 轴用 `U` 表示增量值
- Z 轴用 `W` 表示增量值

```gcode
; 车床增量坐标
G00 U20 W10  ; 等同于 G91 G00 X20 Z10
```

### 坐标平面选择

📚 来源：《数控编程》(王爱玲, 2021) 第2章第4节

```gcode
G17  ; 选择 XY 平面（铣床默认）
G18  ; 选择 XZ 平面（车床默认）
G19  ; 选择 YZ 平面
```

### 常见坐标系指令汇总

| 指令 | 功能 | 说明 |
|------|------|------|
| G53 | 选择机床坐标系 | 取消所有工件坐标系偏移 |
| G54~G59 | 选择工件坐标系 1~6 | 预设的工件坐标系 |
| G90 | 绝对坐标编程 | 所有值相对于工件原点 |
| G91 | 增量坐标编程 | 所有值相对于当前位置 |
| G92 | 设定坐标系 | 将当前点设定为指定坐标值 |
| G17/G18/G19 | 坐标平面选择 | XY/XZ/YZ 平面 |

## 常见问题

1. **G90 和 G91 的区别**
   - G90：绝对坐标，坐标值是终点相对于工件原点的位置
   - G91：增量坐标，坐标值是终点相对于起点的位移量
   - 编程时应明确使用哪种方式，避免混淆

2. **G54 和 G92 的区别**
   - G54：在机床参数中预设，断电后仍然保留
   - G92：在程序中临时设定，断电后消失
   - 推荐使用 G54，更安全可靠

3. **回参考点的作用**
   - 建立机床坐标系的绝对基准
   - 消除丝杠反向间隙误差
   - 开机后必须先回参考点才能进行自动加工

## 总结

- 机床坐标系是机床固有的基准坐标系，通过回参考点建立
- 工件坐标系是编程使用的坐标系，通过 G54~G59 或 G92 设定
- G90 为绝对坐标编程，G91 为增量坐标编程
- 坐标平面通过 G17/G18/G19 选择
- 正确理解坐标系是编写正确加工程序的基础
