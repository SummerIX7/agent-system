# 后处理定制基础

## 适用岗位

适用于编程师和工艺工程人员。后处理负责把 CAM 刀位轨迹转换为特定机床可执行的 NC 程序，是 CAM 编程落地到机床的最后关键环节。

## 学习目标

1. 理解后处理器、机床控制系统和 NC 程序之间的关系。
2. 能识别后处理输出中的程序头、换刀、主轴、冷却、补偿和程序尾。
3. 能说明为什么后处理器不能随意混用。
4. 能列出后处理验证的基本步骤。

## 核心知识点

### 后处理的作用

📚 来源：《CAD/CAM 数控编程技术》(李维, 2022) 第6章

CAM 内部刀路通常不是机床能直接执行的 G 代码。后处理器根据机床结构、控制系统语法、刀库规则、补偿习惯和安全格式，把刀路转成 NC 文件。例如同一条换刀动作，在不同系统中可能输出 `T01 M06`、`TOOL CALL` 或其他格式。

### 输出内容组成

| 模块 | 典型内容 |
|------|----------|
| 程序头 | 程序号、单位、绝对/增量、平面、取消补偿 |
| 换刀段 | T 号、M06、刀长补偿 H |
| 主轴冷却 | S 转速、M03/M04、M08/M09 |
| 切削段 | G00/G01/G02/G03、F 进给 |
| 安全段 | 安全高度、退刀、回参考点 |
| 程序尾 | M05、M09、M30、百分号 |

### 定制范围

后处理定制通常包括程序格式、行号、注释、换刀逻辑、圆弧输出方式、坐标小数位、固定循环、刀具补偿、第四/第五轴输出、程序尾格式等。普通编程师可以调整模板化选项，但涉及机床运动学、多轴变换和系统变量的修改应由有经验人员完成。

## 操作流程 / 编程示例

标准三轴加工程序头示例：

```gcode
%
O2100 (PLATE ROUGH)
G90 G21 G17 G40 G49 G80
G54
T01 M06
S3000 M03
G43 H01 Z50.
M08
```

程序尾示例：

```gcode
G00 Z50.
M09
M05
G91 G28 Z0.
G90
M30
%
```

后处理验证流程：

```text
1. 确认机床型号、控制系统、轴数和刀库方式。
2. 用简单几何生成测试刀路，输出 NC 程序。
3. 检查程序头尾、换刀、补偿、圆弧、固定循环格式。
4. 在仿真软件或机床图形模式中验证轨迹。
5. 空运行并把倍率调低，观察坐标和辅助动作。
6. 首件试切后冻结版本，禁止多人私自修改。
```

## 检查表 / 参数表

| 检查项 | 风险 |
|--------|------|
| 单位 G20/G21 | 英制/公制错误会造成尺寸灾难 |
| 坐标模式 G90/G91 | 增量误用会导致撞机 |
| 平面 G17/G18/G19 | 圆弧插补方向错误 |
| 圆弧 IJK/R | 不同系统格式不同 |
| 换刀安全高度 | 刀具可能碰夹具 |
| 固定循环取消 G80 | 后续动作可能异常 |
| 程序结束 M30 | 程序复位和返回方式 |

## 常见错误与纠偏

1. **借用相似机床后处理**：轴方向或换刀逻辑可能不同。纠偏：每台机床建立独立验证记录。
2. **程序头缺少取消模态指令**：旧状态影响新程序。纠偏：统一输出 `G40 G49 G80` 等安全行。
3. **圆弧输出报警**：IJK 增量/绝对模式不匹配。纠偏：按系统参数调整圆弧格式。
4. **后处理修改无版本管理**：问题难追溯。纠偏：记录修改人、日期、机床、验证结果。

## 练习题

1. 后处理器为什么必须与机床控制系统匹配？
2. 程序头中 `G90 G21 G17 G40 G49 G80` 各有什么作用？
3. 列出一个后处理上线前的最小验证流程。

## 来源与适用边界

本文用于后处理基础培训。后处理定制直接影响机床运动安全，生产环境中必须由授权人员修改并经过仿真、空运行和首件验证。
