# 数控机床基础

## 概述

数控机床（CNC，Computer Numerical Control）是采用数字控制技术对机床的加工过程进行自动控制的自动化机床。数控技术是现代制造业的核心技术之一，广泛应用于航空航天、汽车、模具、医疗器械等领域。掌握数控机床的分类、组成和工作原理是学习数控编程与操作的基础。

## 核心知识点

### 数控机床的定义与特点

数控机床是通过预先编制的程序（G 代码/M 代码）来控制机床的运动轨迹、速度、加工顺序等参数，实现零件的自动化加工。

📚 来源：《数控技术》(刘战术, 2022) 第1章第1节

与传统机床相比，数控机床具有以下特点：
1. **加工精度高**：定位精度可达 0.001mm，重复定位精度高
2. **加工效率高**：可实现多工序复合加工，减少装夹次数
3. **适应性强**：更换程序即可加工不同零件，适合多品种小批量生产
4. **自动化程度高**：减少人工干预，降低劳动强度
5. **一致性好**：批量加工零件尺寸一致性高

### 数控机床的分类

📚 来源：《数控技术》(刘战术, 2022) 第2章第1节

按工艺用途分类：

| 类型 | 典型机床 | 主要用途 |
|------|----------|----------|
| 数控车床 | 卧式车床、立式车床 | 轴类、盘类零件的车削加工 |
| 数控铣床 | 立式铣床、卧式铣床 | 平面、轮廓、型腔的铣削加工 |
| 加工中心 | 立式/卧式加工中心 | 多工序复合加工，自动换刀 |
| 数控磨床 | 平面磨床、外圆磨床 | 高精度表面加工 |
| 数控钻床 | 数控钻床、钻攻中心 | 钻孔、攻丝加工 |
| 数控线切割 | 快走丝、慢走丝 | 模具型腔、异形零件切割 |

按控制系统分类：
- **点位控制**：只控制终点位置，不控制运动轨迹（如数控钻床）
- **直线控制**：控制平行于坐标轴的直线运动
- **轮廓控制（连续控制）**：同时控制多个坐标轴的运动，可加工复杂曲线和曲面（最常用）

### 数控机床的组成

📚 来源：《数控技术》(刘战术, 2022) 第2章第2节

一台完整的数控机床由以下几部分组成：

**1. 程序载体与输入装置**
- 程序载体：存储加工程序的介质（U 盘、CF 卡、网络传输）
- 输入装置：将程序信息读入数控系统

**2. 数控系统（CNC 装置）**
- 核心控制部分，相当于机床的"大脑"
- 功能：程序译码、插补运算、位置控制、I/O 控制
- 主流品牌：FANUC（发那科）、SIEMENS（西门子）、MITSUBISHI（三菱）、华中数控、广州数控

**3. 伺服驱动系统**
- 包括伺服电机和驱动器
- 接收数控系统的指令，驱动机床各轴运动
- 分为开环、半闭环和闭环三种控制方式

**4. 机床本体**
- 床身、立柱、工作台、主轴箱等机械部件
- 要求高刚性、高精度、良好的热稳定性

**5. 辅助装置**
- 刀库和自动换刀装置（ATC）
- 冷却系统、润滑系统、排屑装置
- 液压系统、气动系统

### 数控机床的工作原理

📚 来源：《数控技术》(刘战术, 2022) 第2章第3节

数控机床的加工流程：

```
零件图纸 → 工艺分析 → 编写程序 → 程序输入 → 数控系统译码 → 插补运算 → 伺服驱动 → 机床运动 → 零件加工
```

关键步骤说明：
1. **程序编制**：根据零件图纸和工艺要求，编写 G 代码加工程序
2. **译码处理**：数控系统将程序代码翻译为内部指令
3. **插补运算**：根据起点、终点和曲线类型，计算各轴的运动量
4. **位置控制**：将计算结果转化为伺服电机的控制信号
5. **反馈修正**：通过编码器检测实际位置，与指令位置比较，修正误差

### 数控机床的坐标系

📚 来源：《数控技术》(刘战术, 2022) 第3章第1节

数控机床采用右手笛卡尔坐标系：
- **X 轴**：平行于工件装夹面，水平方向
- **Y 轴**：垂直于 X 轴，水平方向
- **Z 轴**：平行于主轴轴线方向
- **A/B/C 轴**：绕 X/Y/Z 轴的旋转轴

车床坐标系：Z 轴沿主轴方向（纵向），X 轴垂直于主轴（径向）
铣床/加工中心坐标系：Z 轴垂直于工作台向上，X/Y 轴在工作台平面内

## 常见问题

1. **数控机床与普通机床的核心区别**
   - 数控机床用程序控制代替手工操作，精度和效率更高
   - 普通机床依赖操作工的技能水平，数控机床依赖程序质量

2. **如何选择合适的数控系统**
   - FANUC：稳定性好，市场占有率高，适合车床和加工中心
   - SIEMENS：功能强大，开放性好，适合复杂加工
   - 国产系统（华中、广州数控）：性价比高，适合教学和简单加工

3. **伺服系统的开环、半闭环、闭环区别**
   - 开环：无位置反馈，精度较低，成本低
   - 半闭环：检测电机转角，不检测工作台实际位置，精度中等
   - 闭环：直接检测工作台位置，精度最高，成本最高

## 总结

- 数控机床是通过程序自动控制加工过程的高精度机床
- 由数控系统、伺服驱动、机床本体和辅助装置四大部分组成
- 按工艺用途分为车床、铣床、加工中心、磨床等
- 坐标系采用右手笛卡尔坐标系，Z 轴平行于主轴
- 主流数控系统品牌为 FANUC 和 SIEMENS
