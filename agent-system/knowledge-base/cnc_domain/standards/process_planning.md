# 工艺规程制定

## 概述

工艺规程是指导零件加工的技术文件，规定了零件从毛坯到成品的整个加工过程。合理的工艺规程能保证加工质量、提高生产效率、降低制造成本。本文介绍工艺规程的制定方法。

## 核心知识点

### 工艺规程的内容

📚 来源：《机械制造工艺学》(王先逵, 2021) 第2章第1节

工艺规程包括以下内容：
1. **工艺路线**：工序的先后顺序
2. **工序内容**：每道工序的加工内容
3. **切削参数**：切削速度、进给量、切削深度
4. **刀具选择**：每道工序使用的刀具
5. **夹具选择**：每道工序使用的夹具
6. **检验要求**：每道工序的检验项目

### 工艺路线制定原则

📚 来源：《机械制造工艺学》(王先逵, 2021) 第2章第2节

**加工顺序原则**：

```
1. 先粗后精
   粗加工 → 半精加工 → 精加工 → 光整加工

2. 先主后次
   主要表面 → 次要表面

3. 先面后孔
   先加工平面 → 后加工孔

4. 基准先行
   先加工定位基准面 → 后加工其他表面
```

**热处理安排**：
| 热处理类型 | 安排位置 | 目的 |
|------------|----------|------|
| 退火/正火 | 粗加工前 | 消除内应力，改善切削性能 |
| 调质 | 粗加工后 | 提高综合力学性能 |
| 淬火 | 半精加工后 | 提高硬度和耐磨性 |
| 渗碳 | 粗加工后 | 提高表面硬度 |
| 时效处理 | 粗加工后 | 消除内应力 |

### 工序设计

📚 来源：《机械制造工艺学》(王先逵, 2021) 第3章第1节

**工序集中与工序分散**：

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| 工序集中 | 一次装夹完成多个加工面 | 数控加工（推荐） |
| 工序分散 | 每道工序只加工一个表面 | 大批量生产 |

**数控加工推荐工序集中**：
- 减少装夹次数，提高精度
- 减少辅助时间，提高效率
- 减少在制品数量

### 加工余量

📚 来源：《机械制造工艺学》(王先逵, 2021) 第3章第2节

加工余量是从毛坯到成品需要切除的材料量。

**总余量** = 各工序余量之和

**工序余量选择原则**：
| 工序 | 余量范围 (mm) | 说明 |
|------|---------------|------|
| 粗加工 | 1-5 | 去除大部分材料 |
| 半精加工 | 0.5-1 | 为精加工做准备 |
| 精加工 | 0.1-0.3 | 保证最终尺寸 |
| 光整加工 | 0.01-0.05 | 提高表面质量 |

**影响余量的因素**：
1. 前道工序的表面粗糙度
2. 前道工序的表面缺陷层深度
3. 前道工序的形位误差
4. 本道工序的安装误差

### 定位基准选择

📚 来源：《机械制造工艺学》(王先逵, 2021) 第2章第3节

**基准分类**：
- **设计基准**：零件图上标注尺寸的基准
- **工艺基准**：加工和测量时使用的基准
  - 定位基准：装夹时用于定位的基准
  - 测量基准：测量时用于定位的基准
  - 装配基准：装配时用于定位的基准

**定位基准选择原则**：
1. 基准重合原则：尽量选设计基准作为定位基准
2. 基准统一原则：尽量用同一基准加工多个表面
3. 互为基准原则：两个表面互为基准反复加工
4. 自为基准原则：用加工面本身作为基准

### 工时定额

📚 来源：《机械制造工艺学》(王先逵, 2021) 第4章

工时定额是完成一个工序所需的时间。

**工时组成**：
```
总工时 = 基本时间 + 辅助时间 + 服务时间 + 休息时间 + 准备终结时间

基本时间：直接切削加工的时间
辅助时间：装夹、换刀、测量等时间
服务时间：清理、润滑等时间
休息时间：操作人员休息时间
准备终结时间：首件加工前的准备时间（分摊）
```

**基本时间计算**：
```
车削基本时间：Tm = π×D×L / (1000×Vc×f)

D：工件直径（mm）
L：加工长度（mm）
Vc：切削速度（m/min）
f：进给量（mm/r）
```

**铣削基本时间**：
```
Tm = L / Vf

L：加工路径长度（mm）
Vf：进给速度（mm/min）
```

## 常见问题

1. **工序集中和工序分散如何选择**
   - 数控加工推荐工序集中（一次装夹完成多工序）
   - 大批量简单零件可考虑工序分散（专用设备）

2. **加工余量如何确定**
   - 查阅工艺手册获取推荐值
   - 根据加工精度要求调整
   - 考虑前道工序的加工误差

3. **为什么先面后孔**
   - 平面定位稳定可靠
   - 以平面为基准加工孔，精度更高
   - 平面可作为后续工序的定位基准

## 总结

- 工艺规程是指导加工的技术文件
- 加工顺序遵循"先粗后精、先主后次、先面后孔、基准先行"
- 加工余量根据精度要求和前道工序质量确定
- 定位基准选择遵循基准重合和基准统一原则
- 工时定额由基本时间、辅助时间等组成
