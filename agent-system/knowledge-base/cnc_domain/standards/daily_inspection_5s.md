# 设备日常点检与5S现场管理

## 适用岗位

适用于操机工、调机工和班组长。日常点检用于提前发现设备异常，5S 管理用于维持安全、清洁、高效的加工现场，两者共同保证加工稳定性。

## 学习目标

1. 能完成班前、班中、班后的设备点检。
2. 能识别润滑、冷却、气压、液压、主轴、刀库和排屑系统异常。
3. 能按照整理、整顿、清扫、清洁、素养落实 5S。
4. 能用点检记录支持维修和质量追溯。

## 核心知识点

### 日常点检范围

📚 来源：《数控车间现场管理规范》(企业培训教材编写组, 2021) 第2章

| 系统 | 点检内容 | 异常表现 |
|------|----------|----------|
| 润滑 | 油位、油压、润滑报警 | 导轨磨损、轴运动异响 |
| 冷却 | 液位、浓度、喷嘴、泵 | 刀具寿命短、表面烧伤 |
| 气压 | 压力、过滤器、漏气 | 换刀失败、夹紧不足 |
| 液压 | 油温、油位、压力 | 夹具动作异常 |
| 主轴 | 声音、温升、振动 | 表面质量差、轴承风险 |
| 刀库 | 刀套、机械手、刀号 | 换刀报警 |
| 排屑 | 排屑器、过滤网 | 堵屑、冷却液溢出 |

### 5S 管理

| 项目 | 含义 | CNC 现场示例 |
|------|------|--------------|
| 整理 | 区分要与不要 | 清走无用夹具、废刀片 |
| 整顿 | 定位定量标识 | 刀具、量具、扳手定置 |
| 清扫 | 清除脏污 | 清理切屑、油污、地面 |
| 清洁 | 制度化保持 | 点检表、责任区、周期 |
| 素养 | 遵守规则 | 按流程交接班和记录 |

5S 不是打扫卫生，而是让异常更容易被发现。例如地面积油、切屑堆积、量具乱放都会增加安全和质量风险。

## 操作流程 / 编程示例

班前点检流程：

```text
1. 检查机床周边无障碍物、无积水积油。
2. 检查润滑油、液压油、切削液液位。
3. 检查气压、液压和报警状态。
4. 开机回零，低速预热主轴。
5. 检查排屑器和冷却泵运行。
6. 核对刀具、夹具、量具定置状态。
7. 在点检表中记录结果和异常。
```

班后维护流程：

```text
1. 停止主轴和冷却，退到安全位置。
2. 清理工作台、夹具、刀库周围切屑。
3. 擦拭量具并归位，废刀片分类回收。
4. 清洁地面油污，检查防护门和观察窗。
5. 记录设备异常、刀具更换和待处理事项。
```

## 常见错误与纠偏

1. **点检表补填**：失去预防意义。纠偏：点检时同步记录。
2. **只清机器不清地面**：滑倒风险。纠偏：地面纳入责任区。
3. **量具和刀具混放**：损坏量具。纠偏：量具单独定置并防碰撞。
4. **小异常不上报**：最终发展成停机。纠偏：建立异常升级规则。
