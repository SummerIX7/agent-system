# 工艺标准化与文档模板

## 适用岗位

适用于编程师、工艺工程师、调机工和班组长。工艺标准化把经验固化为文件，减少人员差异造成的质量波动，使程序、刀具、夹具、检验和生产记录能够追溯。

## 学习目标

1. 理解工艺卡、刀具清单、装夹图、程序单、检验指导书的作用。
2. 能按统一模板记录 CNC 加工关键参数。
3. 能理解程序版本、审批、发放和变更控制。
4. 能把首件和过程问题反馈到工艺文件。

## 核心知识点

### 工艺文件体系

📚 来源：《机械加工工艺文件编制规范》(工艺标准化教材编写组, 2020) 第1章

| 文件 | 主要内容 | 使用者 |
|------|----------|--------|
| 工艺路线卡 | 工序顺序、设备、工时 | 工艺、生产 |
| 工序卡 | 工步、刀具、参数、装夹 | 调机、操机 |
| 刀具清单 | T/H/D、规格、伸出、寿命 | 编程、调机 |
| 装夹图 | 定位基准、压紧位置、避让 | 调机、操机 |
| 程序单 | 程序号、版本、坐标系、注意事项 | 编程、调机 |
| 检验指导书 | 检验项目、量具、频次 | 质检、操机 |

### 标准化原则

工艺文件应做到编号唯一、版本受控、字段完整、语言清晰、参数可执行、责任可追溯。关键尺寸、关键刀具、特殊安全注意事项不能只写在个人笔记中。

### 程序版本管理

CNC 程序属于受控技术文件。程序修改应记录修改原因、修改内容、修改人、日期、验证结果和生效范围。现场机床中的程序应与受控版本一致，不能多人私自复制覆盖。

## 操作流程 / 编程示例

工序卡模板：

```text
零件号：
工序号：
工序名称：
设备型号：
装夹方式：
工件坐标系：
刀具列表：
  T01 面铣刀 D50 H01 D01 S1200 F600
  T02 立铣刀 D10 H02 D02 S3000 F500
工步：
  1. 粗铣上表面，留量 0.2mm
  2. 精铣外形至尺寸
  3. 钻孔并倒角
检验项目：
特殊注意：
编制/审核/批准：
```

程序变更流程：

```text
1. 发现问题或提出优化需求。
2. 编程师修改 CAM 或 NC 程序。
3. 更新版本号和变更说明。
4. 进行仿真、空运行和首件验证。
5. 审批后发放到现场。
6. 回收旧版本或标识作废。
```

## 检查表 / 参数表

| 字段 | 是否必须 | 说明 |
|------|----------|------|
| 零件号/版本 | 是 | 防止加工错版 |
| 程序号 | 是 | 与机床文件一致 |
| 坐标系 | 是 | G54-G59 明确 |
| 刀具表 | 是 | T/H/D 对应 |
| 切削参数 | 是 | S/F/ap/ae |
| 检验项目 | 是 | 首件和巡检依据 |
| 变更记录 | 是 | 追溯修改 |

## 常见错误与纠偏

1. **程序文件名随意**：现场找错程序。纠偏：统一命名规则。
2. **修改程序不升版**：旧版新版混用。纠偏：版本号和变更记录同步。
3. **刀具清单缺 H/D**：对刀易错。纠偏：刀具表包含补偿号。
4. **检验要求口头传达**：执行不一致。纠偏：写入检验指导书。
