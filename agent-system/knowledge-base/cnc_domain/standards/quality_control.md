# 质量控制标准

## 概述

质量控制是数控加工中保证产品一致性和合格率的重要手段。本文介绍统计过程控制（SPC）的基本方法，包括控制图的使用和过程能力指数的计算。

## 核心知识点

### 统计过程控制（SPC）

📚 来源：《统计质量控制》(张公绪, 2020) 第1章第1节

SPC 是利用统计方法对生产过程进行监控和控制的方法，目的是：
1. 及时发现过程中的异常波动
2. 区分正常波动和异常波动
3. 预防不合格品的产生
4. 持续改进过程质量

### 控制图

📚 来源：《统计质量控制》(张公绪, 2020) 第3章

控制图是 SPC 的核心工具，用于监控过程是否处于稳定状态。

**控制图的组成**：
```
UCL = x̄ + 3σ  （上控制限）
CL  = x̄       （中心线）
LCL = x̄ - 3σ  （下控制限）
```

**常用控制图类型**：

| 控制图 | 用途 | 适用数据 |
|--------|------|----------|
| X̄-R 图 | 监控均值和极差 | 计量数据，样本量 2-10 |
| X̄-S 图 | 监控均值和标准差 | 计量数据，样本量 > 10 |
| X-MR 图 | 监控单值和移动极差 | 单个测量值 |
| p 图 | 监控不合格品率 | 计数数据 |
| c 图 | 监控缺陷数 | 计数数据 |

**X̄-R 图的绘制步骤**：
```
1. 收集数据：至少 25 组样本，每组 5 个
2. 计算每组均值 X̄ 和极差 R
3. 计算总均值 X̄̄ 和平均极差 R̄
4. 计算控制限：
   X̄ 图：UCL = X̄̄ + A2×R̄, LCL = X̄̄ - A2×R̄
   R 图：UCL = D4×R̄, LCL = D3×R̄
5. 绘制控制图并描点
6. 判断过程是否稳定
```

**过程失控的判断准则**：
1. 有点超出控制限
2. 连续 7 个点在中心线同一侧
3. 连续 7 个点呈上升或下降趋势
4. 点在控制限附近聚集（非随机分布）

### 过程能力指数

📚 来源：《统计质量控制》(张公绪, 2020) 第4章

过程能力指数（Cp/Cpk）衡量过程满足公差要求的能力。

**Cp（过程能力指数）**：
```
Cp = (USL - LSL) / (6σ)

USL：上规格限
LSL：下规格限
σ：过程标准差
```

**Cpk（修正过程能力指数）**：
```
Cpk = min[(USL - x̄)/(3σ), (x̄ - LSL)/(3σ)]

x̄：过程均值
```

**Cpk 值与过程能力评价**：

| Cpk 值 | 过程能力 | 说明 |
|--------|----------|------|
| Cpk ≥ 1.67 | 过程能力充足 | 可考虑放宽检验 |
| 1.33 ≤ Cpk < 1.67 | 过程能力满足 | 理想状态 |
| 1.0 ≤ Cpk < 1.33 | 过程能力不足 | 需要加强监控 |
| 0.67 ≤ Cpk < 1.0 | 过程能力严重不足 | 需要改进过程 |
| Cpk < 0.67 | 过程能力极差 | 停止生产，立即改进 |

**Cpk 计算实例**：
```
零件要求：φ50 ± 0.05mm
测量数据：x̄ = 50.01mm, σ = 0.015mm

USL = 50.05mm, LSL = 49.95mm

Cp = (50.05 - 49.95) / (6 × 0.015) = 0.10 / 0.09 = 1.11

Cpk = min[(50.05 - 50.01)/(3×0.015), (50.01 - 49.95)/(3×0.015)]
    = min[0.89, 1.33]
    = 0.89

评价：Cpk = 0.89 < 1.0，过程能力不足，需要改进
```

### 抽样检验

📚 来源：《统计质量控制》(张公绪, 2020) 第5章

抽样检验是从一批产品中抽取部分样品进行检验，根据检验结果判断整批产品是否合格。

**抽样方案类型**：
- 一次抽样：从一批中抽一次，根据不合格数判断
- 二次抽样：第一次抽样后可能再抽一次
- 多次抽样：可能抽多次

**AQL（可接受质量水平）**：
- AQL 是可接受的最高不合格品率
- 常用 AQL 值：0.1%, 0.25%, 0.4%, 0.65%, 1.0%, 2.5%

## 常见问题

1. **如何提高过程能力指数**
   - 减小过程标准差 σ（提高加工精度）
   - 调整过程均值 x̄ 到公差中心
   - 使用更高精度的机床和刀具
   - 优化切削参数

2. **控制图出现异常怎么办**
   - 立即停止生产
   - 查找异常原因（刀具磨损、材料变化、机床故障等）
   - 排除异常原因后重新生产
   - 对异常期间生产的产品进行全检

3. **Cpk 和 Cp 的区别**
   - Cp 只考虑过程的离散程度（6σ）
   - Cpk 同时考虑过程的离散程度和偏移
   - 当过程均值恰好在公差中心时，Cpk = Cp

## 总结

- SPC 是利用统计方法监控和控制过程质量的方法
- 控制图用于判断过程是否稳定
- Cpk 衡量过程满足公差要求的能力
- Cpk ≥ 1.33 表示过程能力满足要求
- 质量控制需要建立完善的文件体系
