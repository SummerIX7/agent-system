# 国家标准汇编

## 概述

国家标准（GB）是我国机械制造行业的基础规范，数控加工领域涉及多个重要国家标准。本文汇总了数控编程、公差配合、表面粗糙度等核心标准的主要内容。

## 核心知识点

### GB/T 8870 — 数控程序格式

📚 来源：GB/T 8870-2019

该标准规定了数控程序的格式、字符集和代码含义。

**程序结构**：
```
%           ; 程序开始符
O0001       ; 程序号
N10 G90...  ; 程序段
...
N999 M30    ; 程序结束
%           ; 程序结束符
```

**字符集**：
- A-Z：地址符（G、M、X、Y、Z、F、S、T 等）
- 0-9：数字
- +、-、.：符号
- %：程序开始/结束符

**常用地址符含义**：

| 地址符 | 含义 | 示例 |
|--------|------|------|
| G | 准备功能 | G01、G02 |
| M | 辅助功能 | M03、M06 |
| X/Y/Z | 坐标值 | X100 Y50 |
| F | 进给速度 | F0.2、F300 |
| S | 主轴转速 | S1000 |
| T | 刀具号 | T01 |
| N | 程序段号 | N10 |
| O | 程序号 | O0001 |
| P/Q/R | 固定循环参数 | P1000 |
| I/J/K | 圆弧圆心坐标 | I10 J0 |

### GB/T 1800 — 极限与配合

📚 来源：GB/T 1800.1-2020

规定了尺寸公差的基本制度和配合类型。

**标准公差等级**：IT01-IT18，精度从高到低

**基本偏差**：
- 孔：A-ZC（大写）
- 轴：a-zc（小写）
- H/h 为基准偏差

**配合类型**：
- 间隙配合：孔 > 轴
- 过渡配合：可能间隙也可能过盈
- 过盈配合：孔 < 轴

### GB/T 1182 — 形位公差

📚 来源：GB/T 1182-2018

规定了形状公差和位置公差的标注方法。

**形状公差**：
| 项目 | 符号 | 说明 |
|------|------|------|
| 直线度 | ─ | 实际直线对理想直线的偏离 |
| 平面度 | ⬜ | 实际平面对理想平面的偏离 |
| 圆度 | ○ | 实际圆对理想圆的偏离 |
| 圆柱度 | ⬭ | 实际圆柱面对理想圆柱面的偏离 |

**位置公差**：
| 项目 | 符号 | 说明 |
|------|------|------|
| 平行度 | ∥ | 两平面/轴线的平行程度 |
| 垂直度 | ⊥ | 两平面/轴线的垂直程度 |
| 同轴度 | ◎ | 两轴线的同轴程度 |
| 位置度 | ⊕ | 实际位置相对于理想位置的偏离 |

### GB/T 1031 — 表面粗糙度

📚 来源：GB/T 1031-2009

规定了表面粗糙度的评定参数和数值系列。

**常用参数**：
- Ra：轮廓算术平均偏差（最常用）
- Rz：轮廓最大高度

**Ra 值系列**（μm）：
```
0.012, 0.025, 0.05, 0.1, 0.2, 0.4, 0.8, 1.6, 3.2, 6.3, 12.5, 25, 50, 100
```

### GB/T 131 — 表面粗糙度标注

📚 来源：GB/T 131-2006

规定了表面粗糙度在图纸上的标注方法。

**标注符号**：
- √：基本符号
- ▽：去除材料方法获得的表面
- ▽（带圆圈）：不去除材料方法获得的表面

### GB 15760 — 机床安全

📚 来源：GB 15760-2018

规定了数控机床的安全技术要求。

**主要内容**：
1. 机床防护：必须有防护罩，防止切屑飞溅
2. 急停装置：必须有急停按钮，位置明显易操作
3. 联锁装置：防护门打开时主轴必须停止
4. 过载保护：机床应有过载保护功能
5. 接地保护：电气系统必须可靠接地

### GB/T 18400 — 加工中心检验条件

📚 来源：GB/T 18400-2010

规定了加工中心的几何精度和工作精度检验方法。

**几何精度检验项目**：
- X/Y/Z 轴定位精度
- X/Y/Z 轴重复定位精度
- 主轴径向跳动
- 主轴端面跳动
- 工作台面平面度

**精度等级**：
| 等级 | 定位精度 (mm) | 重复定位精度 (mm) |
|------|---------------|-------------------|
| 普通级 | 0.015 | 0.008 |
| 精密级 | 0.008 | 0.004 |
| 高精密级 | 0.004 | 0.002 |

## 常见问题

1. **如何查找国家标准**
   - 国家标准全文公开系统：https://openstd.samr.gov.cn/
   - 工标网：http://www.csres.com/
   - 标准出版社购买

2. **GB/T 和 GB 的区别**
   - GB：强制性国家标准，必须执行
   - GB/T：推荐性国家标准，建议执行
   - 数控领域多为 GB/T

3. **数控编程必须遵循哪些标准**
   - GB/T 8870：程序格式
   - GB/T 1800：公差配合
   - GB/T 1031：表面粗糙度
   - GB 15760：安全规程

## 总结

- GB/T 8870 规定了数控程序的格式和代码含义
- GB/T 1800 规定了公差配合制度
- GB/T 1182 规定了形位公差标注方法
- GB/T 1031 规定了表面粗糙度评定参数
- GB 15760 规定了机床安全技术要求
