# 加工中心编程

## 概述

加工中心（Machining Center）是在数控铣床基础上增加了自动换刀装置（ATC）和刀库的数控机床，能在一次装夹中完成多工序加工（铣、钻、镗、攻丝等），是现代制造业中应用最广泛的数控机床之一。

## 核心知识点

### 加工中心的特点

📚 来源：《加工中心编程与操作》(王荣兴, 2022) 第1章第2节

与数控铣床相比，加工中心具有以下特点：
1. **自动换刀**：刀库容量通常为 20-60 把刀具
2. **多工序加工**：一次装夹可完成铣、钻、镗、攻丝等多种加工
3. **高效率**：减少装夹次数和辅助时间
4. **高精度**：减少因多次装夹导致的定位误差

刀库类型：
- **圆盘式刀库**：刀具沿圆周排列，换刀速度快
- **链式刀库**：刀具沿链条排列，容量大
- **帽式刀库**：刀具在主轴上方，结构紧凑

### 自动换刀编程

📚 来源：《加工中心编程与操作》(王荣兴, 2022) 第3章第1节

**换刀指令格式**：
```gcode
M06 T__  ; 换刀指令，T 为刀具号

; 或者分两行写
T02      ; 预选 2 号刀
M06      ; 执行换刀
```

**换刀安全流程**：
```gcode
; 安全换刀的标准流程
G91 G28 Z0    ; Z 轴回参考点（安全高度）
M05           ; 主轴停止
M09           ; 关冷却液
M06 T02       ; 换 2 号刀
G90           ; 恢复绝对坐标
M03 S1200     ; 主轴正转
G43 H02 Z50   ; 刀具长度补偿
M08           ; 开冷却液
```

**注意事项**：
- 换刀前必须将 Z 轴退到安全高度
- 换刀前必须停止主轴
- 换刀后必须建立新的刀具长度补偿
- 刀具号 T 和刀补号 H 必须对应

### 刀具长度补偿

📚 来源：《加工中心编程与操作》(王荣兴, 2022) 第3章第3节

刀具长度补偿的作用：
- 不同刀具长度不同，需要补偿以保证 Z 方向精度
- G43：正补偿（刀具实际长度 > 标准长度）
- G44：负补偿（刀具实际长度 < 标准长度）
- G49：取消刀具长度补偿

**对刀方法**：
1. 使用基准刀具（通常为 1 号刀）设定工件坐标系 Z0
2. 用其他刀具分别触碰工件表面或对刀仪
3. 计算各刀具与基准刀具的长度差，存入 H 补偿表

```gcode
; 使用基准刀具设定 Z0
G92 Z0  ; 或在 G54 中设置 Z 值

; 使用 G43 建立长度补偿
G43 H01 Z50  ; 使用 1 号刀补
G43 H02 Z50  ; 使用 2 号刀补
```

## 常见问题

1. **换刀时碰撞**
   - 原因：未将 Z 轴退到安全高度就执行换刀
   - 解决：换刀前执行 G91 G28 Z0

2. **刀具长度补偿错误**
   - 原因：H 补偿号与实际刀具不对应
   - 解决：确保 T 号和 H 号一致，对刀时仔细测量

3. **攻丝深度不准确**
   - 原因：主轴转速不稳定或进给速度与螺距不匹配
   - 解决：使用刚性攻丝功能，确保 F = 螺距 × 转速

## 总结

- 加工中心的核心优势是自动换刀和多工序加工
- 换刀时必须注意安全：退刀、停主轴、建立新补偿
- 刀具长度补偿（G43/G44）是保证 Z 方向精度的关键
- 固定循环（G81-G89）简化了孔加工编程
- 合理规划加工顺序可提高效率和质量
