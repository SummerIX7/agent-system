# 数控铣床编程

## 概述

数控铣床主要用于加工平面、轮廓、型腔、孔等非回转体零件。本文通过典型零件实例，讲解数控铣床的编程方法，包括平面铣削、轮廓铣削、型腔加工和孔加工等常用操作。

## 核心知识点

### 铣床坐标系与编程特点

📚 来源：《数控铣床编程与操作》(李锋, 2021) 第2章第1节

数控铣床的坐标系特点：
- Z 轴：垂直于工作台向上
- X 轴：工作台左右方向
- Y 轴：工作台前后方向
- 通常使用绝对坐标编程（G90）

### 平面铣削编程

📚 来源：《数控铣床编程与操作》(李锋, 2021) 第4章第1节

**平面铣削程序**：
```gcode
O0001  ; 平面铣削程序
N10 G90 G21 G40 G49  ; 初始化
N20 T01 M06          ; 换 1 号面铣刀（φ50）
N30 M03 S800         ; 主轴正转
N40 M08              ; 开冷却液

; 平面铣削
N50 G00 X-30 Y0 Z50  ; 快速定位到起点上方
N60 G00 Z2           ; 下降到安全高度
N70 G01 Z-1 F100     ; 下刀
N80 G01 X200 F300    ; 铣削平面（单向）
N90 G00 Z5           ; 抬刀
N100 G00 X-30 Y10    ; 移动到下一行
N110 G00 Z2
N120 G01 Z-1 F100
N130 G01 X200 F300   ; 铣削第二行
N140 G00 Z50         ; 抬刀

N150 M09 M05
N160 M30
```

### 轮廓铣削编程

📚 来源：《数控铣床编程与操作》(李锋, 2021) 第5章第1节

**零件要求**：铣削一个矩形轮廓，带圆角

```
    R10
  ┌──────┐
  │      │  80×60
  │      │
  └──────┘
```

**加工程序**：
```gcode
O0002  ; 轮廓铣削程序
N10 G90 G21 G40 G49
N20 T01 M06          ; 换立铣刀（φ10）
N30 M03 S2000
N40 M08

; 使用刀具半径补偿
N50 G00 X-15 Y-15 Z50
N60 G00 Z2
N70 G01 Z-10 F100    ; 下刀深度 10mm
N80 G41 D01 G01 X0 Y-15 F300  ; 左刀补

; 轮廓路径
N90 G01 Y0           ; 移动到轮廓起点
N100 G01 Y50         ; 铣削左侧
N110 G02 X10 Y60 R10 ; 右上圆角
N120 G01 X70         ; 铣削上边
N130 G02 X80 Y50 R10 ; 右下圆角
N140 G01 Y10         ; 铣削右边
N150 G02 X70 Y0 R10  ; 左下圆角
N160 G01 X10         ; 铣削下边
N170 G02 X0 Y10 R10  ; 左上圆角
N180 G01 Y0          ; 回到起点

N190 G40 G00 X-15 Y-15  ; 取消刀补
N200 G00 Z50

N210 M09 M05
N220 M30
```

**刀具半径补偿说明**：
- G41：左补偿（沿进给方向，刀具在工件左侧）
- G42：右补偿（沿进给方向，刀具在工件右侧）
- D01：1 号刀补值（存储在机床参数中）
- G40：取消刀具半径补偿

N20 T02 M06          ; 换键槽铣刀（φ8）

N40 M08

; 螺旋下刀（避免垂直下刀）
N50 G00 X0 Y0 Z50
N60 G00 Z2
N70 G01 Z0 F200

N80 G01 X5 Y5 F300   ; 定位到型腔内

N100 G01 X45 F400    ; 环切第一层
N110 G01 Y35
N120 G01 X5
N130 G01 Y5
N140 G01 X10 Y10     ; 环切第二层
N150 G01 X40
N160 G01 Y30
N170 G01 X10
N180 G01 Y10

; 精加工
N190 G01 Z-10 F100   ; 到最终深度
N200 G42 D02 G01 X0 Y0 F300
N210 G01 X50
N220 G01 Y40
N230 G01 X0
N240 G01 Y0
N250 G40 G00 X25 Y20

N260 G00 Z50
N270 M09 M05
N280 M30

## 常见问题

1. **刀具半径补偿的建立和取消**
   - 必须在切入工件前提供建立补偿（G41/G42）
   - 必须在退出工件后取消补偿（G40）
   - 建立和取消时的移动距离必须大于刀具半径

2. **型腔加工的下刀方式**
   - 垂直下刀：适合有中心切削能力的刀具
   - 螺旋下刀：适合普通立铣刀，避免轴向切削
   - 斜线下刀：适合窄槽加工

3. **固定循环的使用**
   - G81：钻孔循环（浅孔）
   - G83：深孔钻削循环（排屑型）
   - G85：铰孔循环
   - G80：取消固定循环

## 总结

- 铣床编程使用 G90 绝对坐标，三轴联动
- 刀具半径补偿（G41/G42）保证轮廓精度
- 型腔加工需合理选择下刀方式和切削路径
- 孔加工使用固定循环（G81/G83/G85）简化编程
- 合理规划加工顺序：粗加工 → 半精加工 → 精加工
