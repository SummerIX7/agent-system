# 首件检验流程

## 适用岗位

适用于调机工、操机工和质检人员。首件检验用于确认程序、装夹、刀具、参数、坐标系和测量方法是否正确，是批量加工前的质量门禁。

## 学习目标

1. 掌握首件检验的触发条件和基本流程。
2. 能区分全尺寸检验、关键尺寸检验和外观检验。
3. 能根据首件结果决定放行、调整或停机。
4. 能完成首件记录和问题闭环。

## 核心知识点

### 触发条件

📚 来源：《机械加工质量控制》(周华, 2021) 第6章

以下情况通常需要首件检验：新产品首次加工、换批次、换程序、换夹具、换刀具、换操作员、设备维修后、长时间停机后、关键参数调整后。首件合格前不应进入批量自动生产。

### 检验内容

| 项目 | 内容 |
|------|------|
| 尺寸 | 长度、直径、孔距、槽宽、深度 |
| 形位 | 平行度、垂直度、同轴度、跳动 |
| 表面 | 粗糙度、毛刺、划伤、压痕 |
| 材料状态 | 热处理、硬度、毛坯方向 |
| 标识 | 零件号、批次、版本 |

### 判定逻辑

首件检验不是只判断“合格/不合格”，更重要的是定位偏差来源。若尺寸接近公差边界，应提前调整到工艺目标值附近，避免批量加工中因刀具磨损或热变形越界。

## 操作流程 / 编程示例

首件流程：

```text
1. 调机工完成程序验证、装夹、对刀和试切。
2. 加工第一件，保持加工参数和正式生产一致。
3. 清理毛刺和切屑，等待必要的温度稳定。
4. 按检验指导书测量关键尺寸和外观。
5. 记录实测值、量具编号、操作者和时间。
6. 若合格，质检或授权人员签字放行。
7. 若不合格，分析原因并修正程序、刀补、装夹或参数。
8. 修正后重新加工首件，不能用未验证修正直接批量生产。
```

首件记录示例：

```text
零件号：CNC-PLATE-01
程序号：O2301
刀具版本：T01/T02/T03
G54：X/Y/Z 已复核
关键尺寸：孔径 10.002mm，孔距 50.01mm，外形 100.00mm
结论：合格，允许生产 20 件后巡检
```

## 检查表 / 参数表

| 检查点 | 要求 |
|--------|------|
| 图纸版本 | 与工艺卡一致 |
| 程序版本 | 与审批版本一致 |
| 量具 | 在校准有效期内 |
| 尺寸记录 | 实测值而非只写合格 |
| 调整记录 | 记录刀补和参数变化 |
| 放行 | 授权人员确认 |

## 常见错误与纠偏

1. **首件只看外观**：关键尺寸可能超差。纠偏：按检验指导书逐项测量。
2. **用手修毛刺掩盖问题**：批量仍会产生毛刺。纠偏：从刀具和工艺解决。
3. **首件合格但尺寸贴近边界**：后续易漂移。纠偏：调整到目标中值附近。
4. **未记录调整量**：无法追溯。纠偏：建立刀补和参数修改记录。

## 练习题

1. 哪些情况下必须重新做首件？
2. 首件尺寸在公差边界附近但合格，是否可以直接批量生产？
3. 首件不合格时应如何区分对刀问题和程序问题？

## 来源与适用边界

本文用于首件检验流程培训。具体检验频次、签字权限和记录格式以企业质量体系文件为准。
