# 程序空运行与单段执行

## 适用岗位

适用于操机工和调机工。空运行和单段执行是新程序、改程序、换刀后上机验证的基本方法，用于在真正切削前发现坐标、刀具、补偿、路径和安全高度问题。

## 学习目标

1. 区分图形模拟、空运行、单段执行和试切。
2. 掌握新程序首次运行的安全顺序。
3. 能观察程序运行中的坐标、模态和辅助动作。
4. 能在异常时安全暂停和恢复。

## 核心知识点

### 验证层级

📚 来源：《数控机床操作与维护》(刘战术, 2022) 第6章

```text
离线仿真 → 机床图形模拟 → 空运行 → 单段执行 → 小切深试切 → 正式加工
```

离线仿真主要检查刀路和碰撞，机床图形模拟检查系统解释结果，空运行检查实际机床运动，单段执行用于逐句确认风险段。

### 空运行要点

空运行通常不切削，可提高 Z 安全高度、关闭主轴或保持主轴低速，并降低快速倍率和进给倍率。不能因为“空运行没问题”就跳过首件试切，因为空运行无法验证切削力、表面质量和实际尺寸。

### 单段执行

单段模式下，每按一次循环启动只执行一个程序段，适合验证换刀、下刀、接近夹具、建立补偿、孔加工循环和退刀等关键位置。

## 操作流程 / 编程示例

新程序验证流程：

```text
1. 核对程序号、零件号、刀具清单和坐标系。
2. 在图形模拟中检查大致轨迹。
3. 将快速倍率调低，进给倍率调低。
4. 把 Z 零点临时抬高或使用安全平面空运行。
5. 开启单段，逐句执行换刀、靠近工件、下刀前程序段。
6. 确认刀具与夹具、压板、工件无干涉。
7. 恢复正确 Z 零点，小切深试切。
8. 首件检验合格后恢复正式倍率。
```

关键程序段示例：

```gcode
G90 G54 G00 X0 Y0
G43 H01 Z50.
Z5.
G01 Z-2. F100.
```

验证时重点观察：调用的是否为正确 G54，H01 是否对应当前刀具，Z5 是否确实在工件上方，`G01 Z-2.` 是否在安全进给下执行。

## 检查表 / 参数表

| 风险段 | 检查内容 |
|--------|----------|
| 换刀 | 刀库号、刀长、主轴夹紧 |
| 快速定位 | 是否越过夹具或压板 |
| 下刀 | Z 高度、进给速度、冷却 |
| 补偿建立 | G41/G42 引入段是否足够 |
| 固定循环 | R 平面、孔深、G80 取消 |
| 程序结束 | 退刀和主轴冷却关闭 |

## 常见错误与纠偏

1. **倍率过高空运行**：发现异常来不及停。纠偏：首次运行降低倍率。
2. **只看屏幕不看机床**：夹具干涉被忽略。纠偏：观察实际刀具位置。
3. **固定循环后忘记 G80**：后续孔循环继续生效。纠偏：检查每个循环结束。
4. **空运行后直接批量**：无法验证尺寸。纠偏：必须首件试切并测量。

## 练习题

1. 空运行和试切各能发现什么问题？
2. 新程序首次运行为什么要用单段执行？
3. 固定循环验证时为什么要关注 R 平面？

## 来源与适用边界

本文用于程序验证培训。不同系统的空运行、机床锁、辅助功能锁等按钮含义不同，使用前需确认现场设备说明。
