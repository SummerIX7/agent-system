# 数控车床编程

## 概述

数控车床主要用于加工轴类、盘类、套类等回转体零件。本文通过典型零件实例，讲解数控车床的编程方法和技巧，包括外圆车削、端面车削、切槽、螺纹加工等常用操作。

## 核心知识点

### 车床坐标系与编程特点

📚 来源：《数控车床编程与操作》(张思隽, 2022) 第2章第1节

数控车床的坐标系特点：
- Z 轴：沿主轴轴线方向（纵向）
- X 轴：垂直于主轴方向（径向）
- X 轴坐标值通常用直径值编程（直径编程）

刀具说明：
- T0101：1 号刀位，1 号刀补
- 外圆车刀、端面车刀、切槽刀、螺纹刀等

### 轴类零件编程实例

📚 来源：《数控车床编程与操作》(张思隽, 2022) 第4章第2节

**零件要求**：加工一个阶梯轴，材料 45# 钢

```
      ┌───┐
      │   │ φ30
  ┌───┘   └───┐
  │           │ φ40
──┘           └──→ Z
0   20  40  60
```

**加工程序**：
```gcode
O0001  ; 程序号
N10 G99 G21 G40  ; 初始化：每转进给、公制、取消刀补
N20 T0101        ; 换 1 号外圆车刀
N30 M03 S800     ; 主轴正转 800r/min
N40 M08          ; 开冷却液

; 粗车外圆（使用 G71 复合循环）
N50 G00 X45 Z2   ; 快速定位到安全位置
N60 G71 U2 R1    ; 粗车循环：切深 2mm，退刀 1mm
N70 G71 P80 Q130 U0.5 W0.1 F0.3
N80 G00 X26      ; 精加工轮廓起点
N90 G01 Z0 F0.15
N100 X30 Z-2     ; 倒角 C2
N110 Z-20        ; 车 φ30 外圆
N120 X40 Z-20    ; 台阶面
N130 Z-60        ; 车 φ40 外圆

; 精车外圆
N140 G70 P80 Q130  ; 精车循环
N150 G00 X100 Z50  ; 退刀到安全位置

; 切断
N160 T0202        ; 换切槽刀
N170 M03 S400     ; 降低转速
N180 G00 X42 Z-62 ; 定位到切断位置
N190 G01 X0 F0.05 ; 切断
N200 G00 X100 Z50 ; 退刀

N210 M09          ; 关冷却液
N220 M05          ; 主轴停止
N230 M30          ; 程序结束
```

**程序说明**：
- G71：外圆粗车复合循环，自动计算每次切削路径
- U2：每次切深 2mm（直径值 4mm）
- R1：退刀量 1mm
- U0.5：X 方向精加工余量 0.5mm
- W0.1：Z 方向精加工余量 0.1mm

### 盘类零件编程实例

📚 来源：《数控车床编程与操作》(张思隽, 2022) 第5章第1节

**零件要求**：加工一个盘类零件，含内孔

**加工程序**：
```gcode
O0002
N10 G99 G21 G40
N20 T0101        ; 外圆车刀
N30 M03 S800 M08

; 车端面
N40 G00 X60 Z1
N50 G01 Z-0.5 F0.2
N60 G01 X0 F0.15
N70 G00 Z1

; 粗车外圆
N80 G00 X55 Z2
N90 G71 U2 R1
N100 G71 P110 Q150 U0.5 W0.1 F0.3
N110 G00 X46
N120 G01 Z0 F0.15
N130 X50 Z-2
N140 Z-30
N150 X55

N160 G70 P110 Q150
N170 G00 X100 Z50

; 钻孔（使用钻头）
N180 T0303        ; 换钻头
N190 M03 S600
N200 G00 X0 Z2
N210 G74 R1       ; 钻孔循环，每次退刀 1mm
N220 G74 Z-25 Q5000 F0.1  ; 钻到深度 25mm，每次切深 5mm
N230 G00 X100 Z50

; 镗孔
N240 T0404        ; 换镗刀
N250 M03 S800
N260 G00 X20 Z2
N270 G71 U1 R0.5
N280 G71 P290 Q330 U-0.3 W0.1 F0.2  ; 内孔余量为负值
N290 G00 X32
N300 G01 Z0 F0.1
N310 X30 Z-1
N320 Z-20
N330 X20

N340 G70 P290 Q330
N350 G00 X100 Z50
N360 M09 M05
N370 M30
```

### 螺纹加工编程

📚 来源：《数控车床编程与操作》(张思隽, 2022) 第6章

**螺纹车削指令 G32/G92/G76**：

```gcode
; 方法一：G32 单行程螺纹切削
G32 Z-30 F1.5  ; 螺距 1.5mm，长度 30mm

; 方法二：G92 螺纹切削循环（简单螺纹）
G92 X28 Z-30 F1.5  ; 螺纹循环

; 方法三：G76 复合螺纹切削循环（推荐）
G76 P020060 Q100 R0.1
G76 X26.376 Z-30 P974 Q200 F1.5
```

G76 参数说明：
- P020060：精车次数 2、退尾角度 0°、刀尖角度 60°
- Q100：最小切深 0.1mm
- R0.1：精加工余量 0.1mm
- X26.376：螺纹底径
- Z-30：螺纹终点
- P974：牙高 0.974mm（半径值）
- Q200：首次切深 0.2mm
- F1.5：螺距 1.5mm

### 切槽编程

```gcode
; 切槽（使用切槽刀）
T0202          ; 换切槽刀（刀宽 3mm）
M03 S400       ; 降低转速
G00 X42 Z-15   ; 定位到槽的位置
G01 X30 F0.05  ; 切入（径向进给）
G04 P1000      ; 暂停 1 秒（光整槽底）
G01 X42 F0.1   ; 退出
G00 X100 Z50   ; 退刀
```

## 常见问题

1. **G71 循环中精加工轮廓描述错误**
   - 轮廓必须单调递增（X 方向不能有凹陷）
   - 起点和终点的 X 值必须大于毛坯直径

2. **螺纹加工出现乱牙**
   - 原因：主轴编码器信号不稳或螺纹起点不对
   - 解决：确保主轴转速稳定，使用 G76 自动计算切深

3. **切槽时振动**
   - 原因：刀具悬伸过长或切削参数不当
   - 解决：降低进给速度，分多次切削

## 总结

- 数控车床采用直径编程，X 轴坐标值为直径值
- G71 粗车循环和 G70 精车循环是最常用的加工指令
- 螺纹加工推荐使用 G76 复合循环
- 切槽时需降低转速和进给速度
- 合理选择刀具和切削参数是保证质量的关键
