# 多种对刀方法

## 适用岗位

适用于调机工核心技能训练，也适合操机工理解坐标系来源。对刀的目标是建立刀具、工件和机床坐标之间的关系，使程序中的坐标能对应到真实切削位置。

## 学习目标

1. 掌握试切对刀、寻边器对刀、对刀仪对刀和刀长仪对刀的适用场景。
2. 能区分机床坐标系、工件坐标系和刀具补偿。
3. 能解释 X/Y/Z 对刀错误的表现。
4. 能形成对刀后的复核习惯。

## 核心知识点

### 对刀方法比较

📚 来源：《数控机床调试与操作》(王伟, 2022) 第3章

| 方法 | 优点 | 局限 |
|------|------|------|
| 试切对刀 | 直观，适合车床和单件 | 耗时，需要切削 |
| 寻边器 | 适合加工中心 X/Y 找边 | 需考虑寻边器半径 |
| 对刀块 | 操作简单，适合 Z 向 | 需输入块高 |
| 机内测头 | 自动化程度高 | 需校准，成本高 |
| 预调仪 | 不占机床时间 | 刀柄和机床基准需一致 |

### 工件坐标系

常用工件坐标系为 G54-G59。程序中调用 `G54` 后，X/Y/Z 编程坐标相对于 G54 零点解释。若程序使用 G54 而现场设定在 G55，会出现整体偏移。

### 车床对刀特点

车床 X 方向通常按直径编程，外圆试切后输入实测直径；Z 方向常通过端面试切设零。不同系统对几何补偿和磨耗补偿的显示方式不同，应按机床说明执行。

## 操作流程 / 编程示例

加工中心寻边器找 X/Y 零点：

```text
1. 将寻边器装入主轴，低速旋转。
2. 接近工件 X 方向基准边，直到寻边器偏摆。
3. 记录机床坐标，按寻边器半径修正。
4. 将修正后的坐标写入 G54 X。
5. 用同样方法找 Y 方向基准边并写入 G54 Y。
6. 用对刀块或测头确定 Z 零点。
7. 在安全高度运行到 X0 Y0，确认位置合理。
```

Z 向对刀块示例：

```text
对刀块高度 = 50.000mm
刀尖刚接触对刀块时，当前机床 Z = -320.500
若工件上表面为 Z0，则 G54 Z = 当前机床 Z - 对刀块高度
具体输入方式按系统界面提示执行。
```

车床外圆试切：

```text
1. 用当前刀具轻车一段外圆，不退 X，只退 Z。
2. 测量外圆直径，例如 39.96mm。
3. 在刀具几何补偿 X 项输入实测直径。
4. 端面轻切后设定 Z0。
```

## 检查表 / 参数表

| 检查项 | 要点 |
|--------|------|
| 坐标系号 | 程序与现场一致 |
| 对刀工具 | 半径/高度已修正 |
| 刀具号 | 当前刀具与补偿号一致 |
| 单位 | mm/inch 未混淆 |
| Z 安全高度 | 首次运行先在高处验证 |
| 复测 | 首件尺寸验证对刀结果 |

## 常见错误与纠偏

1. **忘记寻边器半径**：零点偏移。纠偏：输入坐标前做半径修正。
2. **Z 零设到毛坯而程序按成品面编制**：深度错误。纠偏：核对程序原点说明。
3. **车床 X 按半径/直径混淆**：尺寸差一倍。纠偏：确认系统编程方式。
4. **对刀后不试运行**：风险直接进入切削。纠偏：先高 Z 运行到关键点。

## 来源与适用边界

本文用于常见对刀方法教学。不同系统界面、补偿栏名称和输入计算方式不同，实际操作应按机床说明书和现场作业指导书执行。
