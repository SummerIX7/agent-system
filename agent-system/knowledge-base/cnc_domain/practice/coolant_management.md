# 切削液配比与管理

## 适用岗位

适用于操机工日常维护和调机工参数优化。切削液影响冷却、润滑、排屑、防锈和刀具寿命，浓度过低或污染严重都会造成加工质量问题。

## 学习目标

1. 理解切削液的冷却、润滑、防锈和清洗作用。
2. 能用折光仪检测乳化液浓度并按比例补液。
3. 能识别发臭、泡沫、锈蚀、沉渣和浓度失控问题。
4. 能根据材料和工序选择冷却方式。

## 核心知识点

### 切削液作用

📚 来源：《金属切削原理与刀具》(李强, 2023) 第8章

切削液通过带走切削热、降低摩擦、冲走切屑和防止工件锈蚀来改善加工过程。铝合金加工要注意粘刀和排屑；不锈钢加工要关注冷却和润滑；铸铁可采用干切或少量冷却，但要控制粉尘和导轨污染。

### 常见类型

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 乳化液 | 冷却好、成本低 | 普通车铣加工 |
| 半合成液 | 清洁性好、稳定性较好 | 加工中心常用 |
| 全合成液 | 冷却强、透明度高 | 磨削、精密加工 |
| 切削油 | 润滑好、冷却较弱 | 攻丝、拉削、深孔 |

### 浓度管理

乳化液常按体积分数配比，普通加工常见浓度约 5%-10%，重切削或攻丝可适当提高。实际浓度必须按切削液厂家说明、材料和企业标准执行。

## 操作流程 / 编程示例

配液流程：

```text
1. 清理水箱浮油和沉渣，确认循环泵正常。
2. 按规定先加水后加原液，边加边搅拌。
3. 用折光仪读取浓度，并乘以产品折光系数修正。
4. 记录日期、浓度、pH、补液量和操作者。
5. 开机循环 5-10 分钟后再次复测。
```

浓度调整示例：

```text
目标浓度：6%
当前浓度：4%
水箱容量：100 L
需要补充的原液量约为：100 × (6%-4%) = 2 L
实际操作应分次加入，循环后复测，避免一次过量。
```

冷却程序示例：

```gcode
M08 (切削液开)
G01 X50. F200.
M09 (切削液关)
```

## 检查表 / 参数表

| 项目 | 检查频次 | 异常处理 |
|------|----------|----------|
| 浓度 | 每班或每日 | 补水或补原液 |
| pH | 每周 | 更换或调整 |
| 浮油 | 每班 | 撇油、查漏油 |
| 沉渣 | 每周 | 清理水箱 |
| 气味 | 每班 | 杀菌或换液 |
| 喷嘴方向 | 每次调机 | 对准切削区 |

## 常见错误与纠偏

1. **直接往水箱倒原液不搅拌**：局部浓度过高。纠偏：先稀释或边循环边加入。
2. **只补水不补原液**：浓度逐渐下降。纠偏：用折光仪定期测量。
3. **喷嘴未对准切削区**：冷却效果差。纠偏：调机时同步调整喷嘴方向。
4. **水箱长期不清理**：细菌、沉渣和堵塞。纠偏：建立定期清槽制度。
