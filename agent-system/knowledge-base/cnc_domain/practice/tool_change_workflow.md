# 刀具更换流程

## 适用岗位

适用于操机工和调机工。刀具更换包括刀具实物安装、刀号登记、长度/半径测量、补偿录入和试切验证，任何一个环节错误都可能导致撞刀或尺寸报废。

## 学习目标

1. 掌握加工中心和数控车床的换刀基本流程。
2. 理解 T 号、H 号、D 号、刀补号之间的关系。
3. 能识别刀具磨损、崩刃、装夹不牢和刀柄污染。
4. 能完成换刀后的验证和记录。

## 核心知识点

### 刀具信息一致性

📚 来源：《数控机床操作与维护》(刘战术, 2022) 第4章

刀具更换时必须保证“实物刀具、刀具清单、程序调用、刀补表”一致。加工中心常见对应关系为 `T01` 调用 1 号刀，`H01` 调用 1 号长度补偿，`D01` 调用 1 号半径补偿。企业也可能采用不同规则，必须按刀具表执行。

### 换刀风险

| 风险 | 后果 | 控制措施 |
|------|------|----------|
| 刀柄锥面有切屑 | 主轴跳动、掉刀 | 清洁锥柄和拉钉 |
| 刀长录入错误 | Z 向撞刀 | 对刀后复核 H 值 |
| 刀号放错刀库 | 调用错误刀具 | 刀库位置双人确认 |
| 刀片未锁紧 | 崩刃、飞出 | 扭矩确认，试转观察 |
| 磨耗未清零 | 尺寸异常 | 换刀后检查磨耗栏 |

## 操作流程 / 编程示例

加工中心换刀流程：

```text
1. 暂停机床并退到安全位置，关闭主轴和冷却。
2. 核对工艺卡中的刀具号、刀具规格、刀柄和伸出长度。
3. 拆下旧刀，检查刀柄、拉钉、刀片和夹头状态。
4. 安装新刀，确认夹紧可靠，刀具伸出符合要求。
5. 将刀具放入指定刀库位置，更新刀具清单。
6. 测量刀长和刀具半径，录入 H/D 或刀具管理系统。
7. 空运行到安全高度，观察换刀动作和刀具方向。
8. 试切并测量关键尺寸，必要时调整磨耗补偿。
```

程序调用示例：

```gcode
T02 M06
S2200 M03
G54 G90 G00 X0 Y0
G43 H02 Z50.
M08
```

车床换刀重点是刀尖方向、刀具中心高、刀位号和几何/磨耗补偿。外圆刀、内孔刀、切槽刀和螺纹刀的刀尖方位不同，录入错误会导致补偿方向异常。

## 检查表 / 参数表

| 检查项 | 要点 |
|--------|------|
| 刀具规格 | 直径、R 角、刃长、材质与工艺卡一致 |
| 刀具伸出 | 满足避让且尽量短 |
| 刀柄状态 | 锥面、拉钉、夹头清洁无损 |
| 补偿号 | T/H/D 或刀位号对应 |
| 磨耗值 | 换新刀后按现场规则清零或继承 |
| 试切结果 | 尺寸和表面合格 |

## 常见错误与纠偏

1. **只换刀不改补偿**：尺寸不可控。纠偏：换刀必须重新确认刀长/刀径。
2. **刀柄未清洁**：主轴跳动变大。纠偏：安装前擦净锥柄和主轴孔。
3. **刀库位置错放**：程序调用错误刀具。纠偏：刀库号与刀具清单逐项核对。
4. **刀具伸出过长**：振动和断刀。纠偏：在避让允许范围内缩短伸出。
