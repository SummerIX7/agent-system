# 测量与检测

## 概述

测量与检测是数控加工质量控制的重要环节。加工后必须对零件进行测量，确认尺寸精度和形位精度是否符合图纸要求。本文介绍常用量具的使用方法和测量技巧。

## 核心知识点

### 常用量具分类

📚 来源：《机械测量技术》(刘翼尔, 2021) 第1章第1节

| 量具 | 精度 | 用途 | 价格 |
|------|------|------|------|
| 钢直尺 | 0.5mm | 粗略测量长度 | 低 |
| 游标卡尺 | 0.02mm | 内外径、深度、台阶 | 低 |
| 外径千分尺 | 0.01mm | 精密外径测量 | 中 |
| 内径千分尺 | 0.01mm | 精密内径测量 | 中 |
| 百分表 | 0.01mm | 形位公差、跳动 | 中 |
| 千分表 | 0.001mm | 高精度形位公差 | 中高 |
| 塞尺 | 0.01mm | 间隙测量 | 低 |
| 三坐标测量机 | 0.001mm | 综合精密测量 | 高 |

### 游标卡尺的使用

📚 来源：《机械测量技术》(刘翼尔, 2021) 第2章第2节

游标卡尺是最常用的量具，可测量外径、内径、深度和台阶。

**读数方法**（以 0.02mm 精度为例）：
```
主尺读数 + 游标对齐格数 × 0.02mm

示例：
主尺读数：25mm
游标第 15 格与主尺对齐
测量值 = 25 + 15 × 0.02 = 25.30mm
```

**使用注意事项**：
1. 使用前检查零位（合拢卡爪，主尺和游标零线应对齐）
2. 测量时卡爪应与工件表面垂直
3. 测量力适中，不宜过大或过小
4. 读数时视线应垂直于刻度面
5. 测量外径时使用外量爪，测量内径时使用内量爪

### 外径千分尺的使用

📚 来源：《机械测量技术》(刘翼尔, 2021) 第2章第3节

千分尺精度为 0.01mm，适用于精密外径测量。

**读数方法**：
```
固定套筒读数 + 微分筒读数

示例：
固定套筒：25mm
微分筒：第 12 格
测量值 = 25 + 12 × 0.01 = 25.12mm
```

**使用注意事项**：
1. 使用前用标准量块校准零位
2. 测量时使用棘轮旋钮，保证测量力恒定
3. 测量面应清洁，无切屑和油污
4. 读数时注意半毫米刻线（固定套筒上的半毫米线）

### 百分表的使用

📚 来源：《机械测量技术》(刘翼尔, 2021) 第3章第1节

百分表用于测量形位公差（圆度、圆柱度、同轴度、跳动等）。

**测量方法**：
1. 将百分表固定在磁力表座上
2. 使测头与被测表面接触
3. 调整指针到零位
4. 旋转工件或移动工件，读取指针变化

**跳动测量**：
```
将百分表测头接触工件外圆
旋转工件一圈
指针的最大变化量即为径向跳动
```

**平面度测量**：
```
将百分表测头接触工件表面
在表面上移动百分表
指针的最大变化量即为平面度误差
```

### 三坐标测量机（CMM）

📚 来源：《机械测量技术》(刘翼尔, 2021) 第5章

三坐标测量机是高精度综合测量设备，可测量零件的尺寸、形位公差等所有几何参数。

**工作原理**：
- 通过探针接触工件表面，记录三维坐标
- 软件计算尺寸、形位公差等参数

**测量精度**：0.001-0.003mm

**适用场景**：
- 高精度零件的首件检验
- 复杂形状零件的综合测量
- 批量生产的抽检

### 测量误差来源

| 误差来源 | 说明 | 控制方法 |
|----------|------|----------|
| 量具误差 | 量具本身的制造误差 | 定期校准 |
| 温度误差 | 工件和量具温度不同 | 在 20°C 标准温度下测量 |
| 人为误差 | 读数不准确、测量力不一致 | 培训操作人员 |
| 方法误差 | 测量方法不当 | 选择合适的测量方法 |

### 温度对测量的影响

钢材的线膨胀系数约为 11.7×10⁻⁶/°C

```
温度误差 = 线膨胀系数 × 长度 × 温度差

示例：测量 100mm 钢件，温差 10°C
误差 = 11.7×10⁻⁶ × 100 × 10 = 0.0117mm
```

**对策**：
- 精密测量应在 20°C ± 2°C 的恒温室进行
- 工件加工后应冷却至室温再测量
- 使用与工件相同材料的量块校准

## 常见问题

1. **游标卡尺零位不准怎么办**
   - 记录零位误差，在测量结果中修正
   - 或更换卡尺

2. **千分尺测量面有划痕**
   - 用油石轻轻修磨测量面
   - 严重时送计量部门修理

3. **如何提高测量精度**
   - 选择精度合适的量具
   - 在标准温度下测量
   - 多次测量取平均值
   - 正确使用量具，避免人为误差

## 总结

- 游标卡尺（0.02mm）和千分尺（0.01mm）是最常用的量具
- 百分表用于形位公差测量
- 三坐标测量机用于高精度综合测量
- 测量时需注意温度影响和人为误差
- 量具需定期校准，保证测量准确性
