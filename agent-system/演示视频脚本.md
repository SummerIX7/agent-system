## 录制操作清单

### 准备环境

1. ✅ 设置 `.env` 中 `MOCK_MODE=true`（确保演示流程稳定、响应快速）
2. ✅ 启动后端：`cd backend && uvicorn main:app --port 8000`
3. ✅ 启动前端：`cd frontend && npm run dev`
4. ✅ 注册测试账号（提前或演示中注册）

### 需要展示的关键页面

| 页面 | URL | 关键操作 |
|------|-----|---------|
| 首页 | `/` | 展示 6 Agent 架构 |
| 登录 | `/login` | 演示登录 |
| 画像 | `/profile` | 填写表单并提交 |
| 仪表盘 | `/dashboard` | 展示雷达图 + 盲区 |
| 工作流 | `/workflow` | 触发生成 + 观察 Agent 状态 |
| 资源 | `/resources` | 切换 4 个标签页 + 来源溯源 |
| 答题 | `/practice` | 答错触发追问 + 实操题批改 |
| 报告 | `/report` | 三项指标 + 匹配曲线 + 学习路径 |

### 注意事项

- 演示视频控制在 **9-10 分钟**（10 分钟以内）
- 确保每个步骤的页面导航流畅
- 答题环节演示 2-3 题即可（包括一次答错追问 + 一次实操题）
- Agent 协同过程是核心亮点，给足时间展示状态变化
- 使用 MOCK_MODE=true 避免 API 延迟影响演示节奏
